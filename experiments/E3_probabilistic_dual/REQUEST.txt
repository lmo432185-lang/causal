# **最新调整实验方案：E3——未知系统下概率化隐藏状态递进发现与双线协同实验**

我建议这次不要简单地在 E2.5 的模型上增加一个概率模块，而是**重新设计隐藏状态发现机制，让状态发现和概率分布从一开始就同时运行、相互反馈。**

你的核心思想我理解为：

1. 完全未知系统，只能观测 X，不提前规定真实隐藏变量数量、名称和因果结构。
2. 模型先从 X 中发现多个候选隐藏状态 W1、W2、W3……每个状态都用概率分布表示，而不是一个固定数值。
3. 从已有状态中继续挖掘新状态，例如从 W1 中发现 Wy。
4. 如果 Wy 是 X 中没有单独发现的信息，就增加一个候选状态；如果 Wy 原来混合在 W1 或其他状态中，就尝试将它分离出来。
5. 另一条路线始终直接回到原始 X，检验 Wy 是否有独立的观测证据。
6. 两条路线都通过联合概率分布预测未来 X，并利用实际到达的 X 更新状态概率。
7. 随着观测不断增加，模型不断修正状态分布、状态数量和状态之间的关系。
8. 在有足够可识别性证据之后，再研究隐藏状态之间的直接、间接因果作用及作用强度。
9. 最终研究因果机制变化能否在预测性能下降之前被发现。

这次最重要的变化是：

本轮核心设计原则

**状态发现线 + 概率更新线，始终并行。**

不是先发现状态，再计算概率。

也不是先计算概率，再决定是否发现状态。

而是每次发现、增加、拆分或合并状态，都必须重新进入联合概率推断；每次新观测带来的概率变化，也可以反过来触发新的状态发现和结构调整。

下面给出完整实验设计，并说明 E2.5 哪些结果可以继承，哪些问题必须重新验证。

# **一、从 E2.5 中继承哪些实验经验？**

E2.5 有几个重要结果，应该直接影响新实验设计。

| E2.5 已有结论             | 新实验如何利用                                   |
| --------------------- | ----------------------------------------- |
| 完整直接提取与递进提取实用等效       | 两条发现路线都保留，不能预设递进更好                        |
| 递进方法优于固定频率和随机字典直接提取   | 保留递进发现，但不能只与弱基线比较                         |

| 联合高斯预测能够评价未来 X        | 继承联合概率预测，但进一步增加隐藏状态后验更新                   |
| 线性递进滤波可以展开成原始 X 的直接滤波 | 增加非线性、不同时间尺度和结构变化条件，检验递进发现是否在更复杂的系统中有独立价值 |

尤其要注意：

E2.5 中的预测概率比较已经比较成熟，但它没有真正实现你要求的：

\\[ P(W_1,W_2,\ldots,W_K\mid X\_{1:t}) \\]

随每次新 X 到达而更新，并反过来影响状态发现和状态数量。

所以，这次不是重复 E2.5，而是把研究重点推进到**概率化隐藏状态的动态发现与结构修正**。

# **二、整体实验架构：两条线同时运行**

这是整个实验的核心。

## **未知系统：只有 X**

**原始观测历史**

\\[ X\_{1:t} \\]

模型只能接触 X，不知道真实 Y、Z 和因果结构

第一条线：递进发现

概率状态 W1

从 W1 发现 Wy

检验新状态、拆分或合并

第二条线：原始 X 验证

直接发现 W1、W2

在 X 中寻找 Wy

检验独立证据

**联合概率推断与在线更新**

\\[ P(W_1,W_2,\ldots,W_K\mid X\_{1:t}) \\]

两条路线使用相同的观测反馈和概率评价规则

**状态结构动态调整**

发现 · 增加 · 拆分 · 合并 · 保留不确定性

**对未来 X 进行概率预测，并接受新观测检验**

这里有一个重要细节：

第二条线不是简单地把第一条线发现的 Wy 再计算一次。

它必须从原始 X 独立学习自己的候选状态表示，避免递进路线把自己的结果重新复制一遍，然后错误地认为得到了独立验证。

两条线共享同一段观测历史，但模型参数、状态发现过程和训练轨迹要独立。

同时，两条线的概率更新机制要保持一致，才能公平比较。

# **三、实验第一阶段：未知系统中的初始概率状态发现**

## **3.1 实验目的**

只给模型 X：

\\[ X_1,X_2,\ldots,X_t \\]

模型不知道：

- X 背后有几个隐藏状态；
- 隐藏状态是否相互影响；
- 是否存在直接和间接作用；
- 是否存在共同驱动因素；
- 哪些状态是独立的；
- 哪些状态只是同一个隐藏机制的不同表示。

模型首先自动发现候选状态：

\\[ W_1,W_2,\ldots,W_K \\]

但这里的 W1、W2 不是固定数值。

而是概率分布。

## **3.2 如何表示状态？**

假设模型最初发现了两个候选状态：

\\[ W_1,\quad W_2 \\]

应该建立：

\\[ q_t(W_1,W_2) = P(W\_{1,t},W\_{2,t}\mid X\_{1:t}) \\]

例如，模型认为当前可能存在以下隐藏状态组合：

| 可能的状态组合     | 概率  |
| ----------- | --- |
| W1 偏低，W2 偏低 | 20% |
| W1 偏低，W2 偏高 | 15% |
| W1 偏高，W2 偏低 | 25% |
| W1 偏高，W2 偏高 | 40% |

这只是帮助理解的离散示例。真正实验中应该采用连续联合概率分布。

例如：

\\[ q_t(W_1,W_2) = \mathcal N(\mu_t,\Sigma_t) \\]

或者使用混合分布：

\\[ q_t(W_1,W_2) = \sum\_{j=1}^{M} \pi\_{j,t}q\_{j,t}(W_1,W_2) \\]

这里：

- \\(\mu_t\\)：状态概率分布的中心；
- \\(\Sigma_t\\)：状态之间的方差和协方差；
- \\(\pi\_{j,t}\\)：不同可能解释的权重。

**不能只保留均值，把概率分布压缩成一个确定的 W1、W2。**

否则就又回到了之前 E2.5 的确定性状态提取问题。

## **3.3 第一阶段需要验证什么？**

1. 能否从 X 中发现多个有用的候选状态？
2. 能否形成合理的联合概率分布？
3. 能否保留状态之间的依赖关系？
4. 能否避免把同一个隐藏动态过程拆成多个重复状态？
5. 在只有一个隐藏状态时，是否能够拒绝不必要的状态扩展？

注意：此时只要求发现候选动态状态，不要求直接认定它们是真实因果变量。

# **四、实验第二阶段：从最高优先级状态中继续发现新状态**

这是你提出的递进式发现机制。

## **4.1 为什么从 W1 开始？**

假设初始模型发现了：

\\[ W_1,W_2,W_3 \\]

但它们不一定具有相同的信息量。

我们可以根据状态的预测贡献、后验不确定性和未解释信息，确定下一步探索的优先级。

例如：

| 状态 | 对未来 X 的预测贡献 | 当前不确定性 | 探索优先级 |
| -- | ----------- | ------ | ----- |
| W1 | 较高          | 较高     | 第一    |
| W2 | 中等          | 较低     | 第二    |
| W3 | 较低          | 较高     | 第三    |

这里不能只按预测贡献排序。否则模型容易不断选择最容易预测的状态，而忽略较弱但可能重要的隐藏作用。

建议采用综合探索优先级：

- 对未来 X 尚未解释的信息；
- 状态后验不确定性；
- 独立测试中可重复的预测贡献；
- 尚未被其他候选状态解释的动态特征。

选择 W1 作为当前探索对象。

## **4.2 从 W1 中发现 Wy**

模型不再只分析 W1 当前的一个估计值，而是分析它的整个概率表示和相关历史：

\\[ q_t(W_1\mid X\_{1:t}) \\]

然后在 W1 中寻找尚未被充分表达的动态信息。

发现候选：

\\[ W_1\rightarrow W\_{1-y} \\]

这里的箭头仅表示模型的递进发现过程，暂时不代表真实因果关系。

新的候选状态也必须用概率表示：

\\[ q_t(W_1,W\_{1-y}\mid X\_{1:t}) \\]

不能直接得到一个确定的 Wy。

# **五、实验第三阶段：另一条线从原始 X 独立验证 Wy**

这是你一直强调的另一条并行路线。

假设递进路线已经发现了：

\\[ W_1\rightarrow W\_{1-y} \\]

接下来，第二条路线不经过 W1。

而是重新从原始 X 历史中学习：

\\[ X\_{1:t}\rightarrow W_y' \\]

并建立：

\\[ q_t(W_y'\mid X\_{1:t}) \\]

然后比较两条路线。

| 比较内容 | 递进路线            | 原始 X 路线       |
| ---- | --------------- | ------------- |
| 信息来源 | W1 的概率状态及其历史    | 原始 X 历史       |
| 状态表示 | 联合概率分布          | 联合概率分布        |
| 参数学习 | 独立训练            | 独立训练          |
| 观测反馈 | 新 X 更新后验        | 新 X 更新后验      |
| 主要任务 | 挖掘 W1 中未充分表达的信息 | 检验 X 是否也支持该信息 |

这里有三种结果：

**结果一：两条路线都发现了相似的信息。**

说明这类动态信息可以从不同表示路径中重复发现。

但仍不能证明它是一个真实物理变量。

**结果二：递进路线发现了 Wy，原始 X 路线没有发现。**

不能立即认为递进路线发现了一个新变量。

需要进一步检查：

- 是不是 W1 的表示放大了某种信息？
- 是不是原始 X 路线的模型能力不足？
- 是不是该信息只能通过特定的历史组合被识别？
- 它能否在新的独立 X 轨迹中稳定预测未来？

**结果三：原始 X 路线也发现了 Wy，但概率分布不同。**

这是非常值得研究的情况。

例如：

\\[ q^{(1)}(W_y\mid X) \neq q^{(2)}(W_y'\mid X) \\]

即使两者的预测信息相似，也可能存在不同的潜在状态解释。

此时不能强行让两个分布变成一样，而应该研究：

- 两个表示是否只是尺度或坐标不同？
- 是否存在多个等价的隐藏状态解释？
- 是否有一种解释更稳定？
- 是否有足够证据将其区分为不同状态？

**这一步的意义不是要求两条路线必须找到相同的物理变量，而是检查递进发现是否具有独立于原始直接提取的有效结构信息。**

# **六、实验第四阶段：双线并行的联合概率更新**

这是这次最核心的数学部分。

你原来提出的想法是：

先根据不同隐藏状态的概率，推测不同的 X；再把真实 X 与预测 X 对比，根据预测表现修正状态概率。

这个思路可以建立成一个完整的概率推断过程。

## **6.1 先建立隐藏状态的联合分布**

假设目前有两个候选状态：

\\[ W_1,W_2 \\]

模型建立：

\\[ q_t(W_1,W_2) = P(W\_{1,t},W\_{2,t}\mid X\_{1:t}) \\]

例如：

| 可能组合 | 先验概率 |
| ---- | ---- |
| A    | 20%  |
| B    | 50%  |
| C    | 30%  |

这三个组合分别对应不同的 W1、W2 状态取值。

实际计算时，不是简单地取三个代表值，而是从完整的联合分布中进行积分或抽样。

## **6.2 利用不同状态组合预测 X**

需要建立一个观测模型：

\\[ P(X\_{t+1}\mid W\_{1,t+1},W\_{2,t+1},X\_{1:t}) \\]

同时还需要状态转移模型：

\\[ P(W\_{t+1}\mid W_t) \\]

把两者结合，就能得到未来 X 的概率预测：

\\[ P(X\_{t+1}\mid X\_{1:t}) = \int P(X\_{t+1}\mid W\_{t+1},X\_{1:t}) P(W\_{t+1}\mid X\_{1:t}) \\,dW\_{t+1} \\]

这里最重要的是：

**不是让每一种状态组合只预测一个 X，而是让每一种状态组合都产生一个 X 的概率分布。**

因此，最终会得到不同候选解释对应的观测概率。

## **6.3 真实 X 到达后更新状态概率**

假设模型原来认为：

- A：20%
- B：50%
- C：30%

现在实际观测到了：

\\[ X\_{t+1}=x\_{t+1} \\]

根据不同状态组合对实际 X 的解释能力，计算似然：

\\[ P(x\_{t+1}\mid A,X\_{1:t}) \\]

\\[ P(x\_{t+1}\mid B,X\_{1:t}) \\]

\\[ P(x\_{t+1}\mid C,X\_{1:t}) \\]

然后使用贝叶斯更新：

\\[ P(A\mid X\_{1:t+1}) \propto P(x\_{t+1}\mid A,X\_{1:t})P(A\mid X\_{1:t}) \\]

B、C 同样计算。

例如，更新后可能变成：

| 可能组合 | 更新前 | 更新后 |
| ---- | --- | --- |
| A    | 20% | 5%  |
| B    | 50% | 85% |
| C    | 30% | 10% |

这只是演示数字。

真实实验中，概率变化必须由实际观测似然决定，不能人为规定。

## **6.4 这种更新还要反过来影响状态发现**

这是你强调的双线并行，不能漏掉。

假设连续一段时间以后，模型发现：

- W1 的后验分布始终较稳定；
- W2 的后验分布存在两种不同解释；
- 某个新的候选 Wy 能明显改善后续 X 的概率预测；
- 但 Wy 与 W1 的关系仍然不确定。

此时就应该重新检查：

\\[ P(W_1,W_2,W_y\mid X\_{1:t}) \\]

模型可以提出拆分、增加或合并的候选结构，再比较不同结构的样本外概率预测。

也就是说：

\\[ \boxed{ \text{状态发现} \rightleftarrows \text{联合概率更新} } \\]

每一次状态结构改变，联合概率模型都必须重新计算。

每一次概率分布发生系统性变化，也可以触发新的状态发现。

这才是你要求的两条线同时进行。

# **七、概率更新必须增加一个防止自我欺骗的机制**

这里我认为是新方案中最需要认真设计的地方。

你提出用预测 X 与真实 X 的接近程度来修正状态概率，这个方法是可行的，但有一个风险：

**模型可能只是不断调整隐藏状态，让它越来越容易解释已经看过的 X，却不一定能够真正预测未来 X。**

举个例子。

模型发现 W1、W2 之后，看到：

\\[ X\_{t+1}=10 \\]

于是不断调整 W1、W2，使它们组合起来刚好能够解释 10。

这时模型可能得到很好的历史拟合。

但如果下一个观测：

\\[ X\_{t+2}=15 \\]

模型又必须大幅修改状态。

这说明它可能只是在追随已经出现的 X，而不是学到了稳定的动态机制。

因此，我建议把每次观测严格分成三个步骤：

**第一步：预测**

新观测尚未进入模型

\\[ P(X\_{t+1}\mid X\_{1:t}) \\]

使用当前状态概率预测下一时刻 X，并保存预测结果。

**第二步：评价**

真实 X 到达

将预测分布与实际 X 比较，计算联合 NLL、CRPS 等评分。

**第三步：更新**

更新后验

\\[ P(W\_{1:t+1}\mid X\_{1:t+1}) \\]

用新观测修正状态概率，然后决定是否触发状态扩展、拆分或合并。

必须先记录预测，再使用观测更新。

不能先看到 X，再调整概率，最后把调整后的概率拿来证明之前预测准确。

此外，状态结构的拆分和合并必须在独立确认数据上决定，最终测试数据只能用于最后评价，不能参与模型选择。

# **八、实验第五阶段：概率反馈驱动状态扩展、拆分和合并**

这一部分要把你原来提出的状态调整真正变成算法。

我建议不直接使用固定的状态数量，而是使用候选结构搜索。

例如：

初始结构：

\\[ M_1=\\{W_1,W_2\\} \\]

递进路线发现 Wy 后，提出：

\\[ M_2=\\{W_1,W_2,W_y\\} \\]

如果 W1 与 Wy 存在混合关系，还可以提出：

\\[ M_3=\\{W\_{1a},W\_{1b},W_2\\} \\]

如果 Wy 与 W2 重复，则提出：

\\[ M_4=\\{W_1,W_2\\} \\]

但重新调整 W2 的状态表示。

这时需要比较不同候选结构。

| 评价项目        | 主要目的               |
| ----------- | ------------------ |
| 未来 X 联合 NLL | 看哪种结构更能解释未见观测      |
| CRPS        | 看整体预测概率分布          |
| 后验校准        | 看状态概率是否可信          |
| 复杂度惩罚       | 防止增加状态就自动获得更好的训练拟合 |
| 状态稳定性       | 看不同数据批次是否得到相似结果    |
| 拆分、合并复现率    | 看结构调整是否可靠          |

这里我建议加入一个模型证据指标：

\\[ P(X\_{1:t}\mid M_j) \\]

它表示某一种候选状态结构 \\(M_j\\) 对整个观测数据的解释能力。

通过模型证据或带复杂度惩罚的样本外预测评分，可以比较不同结构。

但要注意，单纯最大化模型证据也不能证明结构就是物理真实结构。不同隐藏结构仍可能具有相同的观测分布。

# **九、完整实验条件应该怎么设置？**

这次要继承 E2.5 的系统设计，同时增加新的未知结构挑战。

我建议分为两层。

## **9.1 第一层：已知真值、未知模型**

这里的“未知”指模型未知。

实验设计者知道真实生成机制，但把它封存，不提供给模型。

模型只接触 X。

| 系统 | 隐藏结构      | 研究目的         |
| -- | --------- | ------------ |
| S0 | 无隐藏状态     | 检查是否凭空增加状态   |
| S1 | 单隐藏状态     | 检查是否错误拆分     |
| S2 | 两个串联隐藏状态  | 检查能否发现不同动态信息 |
| S3 | 两个并联隐藏状态  | 检查能否发现并行信息   |
| S4 | 多个状态加共同驱动 | 检查是否错误解释共同信息 |

这些是模拟实验的真值条件，不是模型事先知道的结构。

其中 S2、S3、S4 需要设计不同的信息强度：

- 弱信息；
- 接近可检测边界的信息；
- 强信息。

还要分别改变：

- 隐藏状态的持续性；
- 观测噪声；
- 动态传递延迟；
- 状态间相关程度；
- 非线性程度；
- 参数变化速度。

不能把所有条件都同时变动后，就把结果归因于某一个参数。

## **9.2 第二层：观测分布等价和不可识别对照**

这一层非常重要。

专门构造两套不同隐藏机制：

\\[ M_A\neq M_B \\]

但是：

\\[ P(X\_{1:T}\mid M_A) = P(X\_{1:T}\mid M_B) \\]

或者在预定精度范围内无法区分。

这时应该检验：

模型是否能够意识到存在多个可能解释，而不是强行选择一个。

如果它能够输出：

- 多个候选结构；
- 对不同结构的后验概率；
- 无法区分时的低置信度；
- 需要额外干预才能区分的提示；

那么即使没有恢复唯一的真实因果结构，也是一个有价值的结果。

因为它解决的是隐藏状态识别的边界问题。

# **十、最重要的四组对照实验**

这次不能只比较递进发现和直接发现，还必须把概率更新单独作为实验因素。

建议采用完整的 2×2 双因素实验。

| 实验组 | 状态发现 | 概率更新     | 研究目的     |
| --- | ---- | -------- | -------- |
| A   | 直接发现 | 不进行在线更新  | 基础直接提取   |
| B   | 直接发现 | 在线联合概率更新 | 单独检验概率更新 |
| C   | 递进发现 | 不进行在线更新  | 单独检验递进发现 |
| D   | 递进发现 | 在线联合概率更新 | 检验两种机制结合 |

这里的“不进行在线更新”并不是不使用概率，而是保留概率状态表示，只是不利用每次新观测重新更新状态后验。这样才能公平判断在线更新本身的作用。

另外，我建议增加两个诊断对照：

| 诊断组 | 具体做法         | 目的             |
| --- | ------------ | -------------- |
| E   | 直接发现，但固定状态结构 | 判断动态拆分、合并有没有价值 |
| F   | 递进发现，但固定状态结构 | 判断概率反馈是否真正改变结构 |

这样最终可以回答六个问题：

1. 直接发现本身能否发现隐藏动态信息？
2. 递进发现本身能否发现更多信息？
3. 概率在线更新是否改善状态估计？
4. 概率反馈是否能够帮助模型拆分和合并状态？
5. 递进发现与概率更新结合后，是否产生额外收益？
6. 是否存在完整直接提取无法稳定发现，但递进概率化方法可以发现的情况？

尤其是第五个问题，是新实验最重要的创新检验。

# **十一、评价指标：不能只看预测准确率**

这次要把评价分成四个层次。

## **第一层：未来 X 的概率预测**

这是所有模型共同的外部检验。

| 指标              | 评价内容                       | 越好方向 |
| --------------- | -------------------------- | ---- |
| 联合 NLL          | 实际出现的 X 在模型联合概率分布中是否得到合理支持 | 越低越好 |
| CRPS            | 每个预测变量的整个概率分布是否合理          | 越低越好 |
| Energy Score    | 多维联合概率预测整体是否合理             | 越低越好 |
| Variogram Score | 不同预测变量、不同时间步之间的依赖结构是否合理    | 越低越好 |

尤其要保留未来 1、2、5、10、20 步的分别评价。

因为你的研究不仅关注预测是否准确，还关注较远时间尺度的隐藏信息是否逐渐显现。

## **第二层：隐藏状态的概率质量**

这里有一个特殊问题：

在真实未知系统中，我们没有 Y、Z 的准确值，因此不能直接计算它们的真实后验覆盖率。

所以要分两种评价环境。

**模拟系统：**

模型冻结后，才使用真实 Y、Z 评价：

- 状态后验 NLL；
- 状态 CRPS；
- 90% 后验区间覆盖率；
- 联合后验覆盖率；
- 状态间相关结构的恢复情况。

这里的真实值只用于事后评价，绝不能进入训练和在线更新。

**真实系统：**

没有真实隐藏状态，就不能声称得到了 Y、Z 的准确率。

只能评价：

- 未来 X 的预测校准；
- 不同数据批次下的后验稳定性；
- 不同候选状态结构的可重复性；
- 模型对新观测的解释能力。

这一区别必须写进论文。

## **第三层：状态发现和结构调整**

这是你课题中很重要的一层。

| 指标      | 解释                 |
| ------- | ------------------ |
| 状态数量误差  | 发现的候选状态数量与模拟真值的差异  |
| 状态拆分准确率 | 是否把混合状态正确拆开        |
| 状态合并准确率 | 是否将重复状态正确处理        |
| 状态扩展错误率 | 是否凭空增加了无效状态        |
| 状态发现延迟  | 隐藏信息出现后多久才能发现      |
| 状态结构稳定性 | 不同种子、不同时间段是否得到稳定结果 |

## **第四层：因果关系恢复的辅助评价**

这一层只能在具有已知真值的模拟系统中进行：

- 直接作用识别准确率；
- 间接作用识别准确率；
- 共同驱动误判率；
- 因果作用强度估计误差；
- 因果方向识别准确率。

特别强调：状态之间的统计依赖不能直接当作因果边。必须增加结构识别模型和可识别性对照。

# **十二、怎样把实验推进到动态因果失效预警？**

这是最终目标，但我不建议 E3 一开始就直接做预警。

先让 E3 把隐藏状态的概率表示、结构更新和可识别性问题解决。

之后设计 E4。

## **E4：动态因果机制变化与失效预警**

假设 E3 最终发现了一组候选状态：

\\[ W_1,W_2,W_3 \\]

并且在满足识别假设的条件下，进一步得到：

\\[ W_1\rightarrow W_2\rightarrow X \\]

以及：

\\[ W_3\rightarrow X \\]

这里才开始研究动态因果关系。

建议构造四种失效实验：

| 失效类型 | 发生变化的内容   | 要研究的问题          |
| ---- | --------- | --------------- |
| F1   | 上游状态发生变化  | 能否从上游概率分布发现异常？  |
| F2   | 传递强度变化    | 能否发现上游到下游的作用减弱？ |
| F3   | 传递延迟变化    | 能否发现原有传递关系发生改变？ |
| F4   | 因果连接消失或新增 | 能否发现原有机制失效？     |

例如，原来的系统是：

\\[ Y\rightarrow Z\rightarrow X \\]

正常时期：

\\[ P(Z\_{t+1}\mid Y_t) \\]

具有稳定的条件分布。

后来 Y 首先发生变化。

模型可以通过上游状态的后验变化，计算：

\\[ P(Z\_{t+1}\mid X\_{1:t}) \\]

并进一步预测：

\\[ P(X\_{t+2}\mid X\_{1:t}) \\]

如果上游变化会导致下游状态进入历史上少见的概率区域，那么就可能提前发现机制变化的风险。

但是这里必须检验一个关键问题：

**上游状态变化是否真的能比下游预测误差更早出现？**

不能预先假设一定能够。

还要比较：

1. 上游状态概率变化的发现时间；
2. 因果连接强度变化的发现时间；
3. 传统预测误差报警时间；
4. 实际预测性能开始明显下降的时间。

最终评价：

\\[ \text{预警提前量} = T\_{\text{预测失效}} - T\_{\text{预警}} \\]

同时报告误报率、漏报率和不同失效强度下的检测延迟。

尤其要增加一种重要对照：

上游状态虽然发生变化，但没有真正影响下游预测。

如果模型仍然发出大量预警，说明它只是发现了状态异常，并没有真正发现因果机制失效。

# **十三、最新实验的执行顺序**

我不建议把所有内容一次性塞进一个大型实验。应该按下面顺序执行，但每个阶段的状态发现和概率更新都保持双线并行。

## **E3 实验执行路线**

1. **E3.1：概率化初始状态发现**

   只输入 X，建立候选状态的联合概率分布，检验初始状态发现能力。
2. **E3.2：递进与直接双线发现**

   一条从 W1 中发现 Wy，另一条直接从 X 中寻找 Wy，两条独立训练。
3. **E3.3：联合概率在线更新**

   每次新 X 到达，都同时更新两条路线的状态后验和未来 X 的预测分布。
4. **E3.4：概率反馈结构调整**

   根据独立观测证据，提出状态增加、拆分、合并或保留不确定性。
5. **E3.5：未知结构和可识别性检验**

   使用无隐藏、单隐藏、串联、并联、共同驱动及观测分布等价系统，评价整个机制。
6. **E3.6：公平对照与独立复现**

   对比四组主实验，使用新的测试轨迹和独立随机种子复现。

E3 完成后的下一阶段

**E4：动态因果变化和提前预警**

只有在隐藏状态和因果关系具有足够识别证据时，才进入这一阶段。

# **十四、实验规模和数据划分建议**

这部分我建议比 E2.5 更严格。

| 项目      | 建议设置                   |
| ------- | ---------------------- |
| 初始系统    | 5 类基础结构                |
| 信息强度    | 弱、中、强                  |
| 额外动力学条件 | 持续性、噪声、延迟、非线性          |
| 随机种子    | 初步每条件20个，重要结果扩展至30–50个 |
| 训练集     | 轨迹级划分                  |
| 模型选择集   | 独立轨迹                   |
| 结构确认集   | 独立轨迹                   |
| 测试集 A   | 第一批独立轨迹                |
| 测试集 B   | 第二批独立轨迹                |
| 在线评价    | 按时间顺序逐步预测、评价、更新        |

建议保留 E2.5 的嵌套训练规模对照，但这次增加更小的数据量条件，例如 20、50、100、200、400 条轨迹。

这样才能检验概率递进发现是否在数据不足时具有优势。

所有实验模型：

- 训练时只接触 X；
- 不能提前知道隐藏状态数量；
- 不能提前知道真实因果图；
- 不能读取真实生成参数；
- 不能通过测试集调整概率分布；
- 不能用真实 Y、Z 帮助状态拆分。

真实隐藏变量和真实因果结构由实验评价程序封存，模型输出冻结后再解封。

# **十五、这次实验必须提前规定什么结果才算成功？**

我建议在实验开始前就冻结成功标准，避免模型跑完之后再根据结果解释。

| 研究问题      | 成功标准                         |
| --------- | ---------------------------- |
| 初始概率状态发现  | 未见 X 上的概率预测有效，且状态后验没有严重失准    |
| 递进发现新状态   | 能在独立数据中重复发现原先未充分表达的信息        |
| 原始 X 独立验证 | 第二条路线能够发现相应的观测信息，而不是复制训练结果   |
| 概率在线更新    | 相比不更新后验的对照，改善未来 X 的概率预测或状态恢复 |
| 状态拆分      | 拆分后在独立测试中获得稳定收益，而不是只改善训练拟合   |
| 状态合并      | 合并后没有丢失有意义的预测信息，且复杂度有所降低     |
| 双线协同      | 递进发现与在线概率更新存在可重复的额外收益        |
| 可识别性      | 能区分可识别结构和观测上无法区分的结构          |

还要增加三个防止错误结论的要求：

**第一，防止状态标签和坐标不唯一。**

例如：

\\[ W_1,W_2 \\]

与：

\\[ W_1+W_2,\ W_1-W_2 \\]

可能只是同一个潜在空间的不同表示。因此，需要使用独立轨迹、跨时间稳定性和不变预测关系检验状态身份，不能单纯比较两个模型的状态名称或数值。

**第二，防止概率模型过度灵活。**

如果模型可以随意增加状态、扩大方差、调整相关结构，就可能通过复杂模型解释所有观测。因此必须使用独立预测评分、复杂度惩罚、后验校准和状态扩展错误率共同约束。

**第三，不能把两条路线的相似结果当成独立物理证据。**

两条路线虽然独立训练，但都来自 X。它们的一致只能增强观测信息的可重复性，不能单独证明真实物理变量的身份。

# **十六、我对这次修改的最终判断**

我认为，这次应该把研究重点从原来的：

> 从 X 中提取隐藏状态，再从隐藏状态中继续提取更多状态。

提升为：

> 在未知系统中，构建一种概率化、递进式与直接式双路线协同的隐藏状态发现机制。模型仅利用 X 的观测历史，同时发现和扩展候选隐藏状态，通过联合概率预测、实际观测反馈和在线后验更新，不断判断候选状态是否具有独立信息，以及是否需要增加、拆分、合并或保留不确定性。在此基础上，进一步研究隐藏动态状态的可识别性、因果关系及其动态变化，最终实现预测失效的提前预警。
