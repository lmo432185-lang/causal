# 实现前固定的补充细节

- 线性高斯候选K上限3，并不保证所有真实机制可容纳。2步延迟条件额外缓存也是潜在动力学状态，模拟隐藏维数为4，此条件含明确容量失配；不能将少恢复一维都算成发现算法失败。
- 递进后验候选采用2条精确FFBS后验路径抽样，EM固定5次；所有路线用同样EM预算。状态空间推断用C++数值内核加速，开发测试与直接高斯条件分布核对。
- 同一路训练池按自身X标准差归一化，输出概率密度带正确Jacobian返回原始单位；独立见证池独立归一化，不交换参数。
- CRPS与90%覆盖在时距1/2/5/10/20的边际上平均；Energy Score用两套各16个独立联合抽样的无偏配对估计，避免将16个样本的全部二次配对当必需。Variogram Score对这5个时距间10对做权重1/时间差的p=0.5评分。各组使用共同随机数；不将随机样本当额外实验重复。
- 确认候选图用独立40条轨迹、双路线预测非劣；强新增证据把所有系统/种子/规模/路线/相邻维数的确认检验作一个Holm族。未通过强新增不等同证明无隐藏状态；保留的非劣候选仍只是可推断预测解释。
- A/C前40个观测滤波初始化后停止测量更新，不是完全不读X：其观测AR项仍用当前X。G每个预测起点从最近41个观测（40个滞后加当前）重建概率后验，固定初始K，独立两路线固定等权，作为有最新信息的强直接参照。
- 固定结构E/F保持选择集确定的K，但同K的两条路线概率仍随观测更新，避免将路径更新与维数更新混为一谈。
- 不进行物理因果边分类。观测等价实验是构造性等价拒判检查，不宣称训练出了任意未知因果图的可识别性判别器。
