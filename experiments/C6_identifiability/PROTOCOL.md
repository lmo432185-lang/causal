# C6：可识别性与信息增益实验协议

机器可核对的冻结协议为 `PROTOCOL.json`；测试开始前将协议、生成器、推断代码、运行器及训练产物的 SHA256 写入 `results/TEST_START.json`。

本实验包含 C6-A（仅 X）、C6-B（配对增加传感器）和 C6-C（对源头 Y 施加随机化已知输入）。不开展真实数据 D，不修改或调优 C5 的 M3。

四个候选机制：A 一阶传递、B 直接作用、C 两级传递、D 时变传递。除了 B，其余以总平均响应滞后匹配，避免只按总体滞后来认标签。候选结构库已知，单轨迹标签不参与训练；这属于有结构假设的模型选择，不是任意未知结构发现。真实源、传递状态、响应参数和起点只供评价。

训练阶段只用健康 X 学习背景 AR 参数；用混合后不带机制标签的训练 X 选择半正态幅度先验；传感器噪声方差只用独立健康传感器数据估计。测试起点、幅度与响应尺度均不传入被动推断。

每种噪声、响应尺度、真实机制各有两批各100条测试轨迹。配对使用同一 X 比较新增信息；相关的机制及响应尺度共享扰动，因此统计单位是“噪声×批次×独立轨迹”，先在其内部平均，不把重复配对当独立样本。

八个预设主要增量：四机制新增 V_U 的三档噪声；被动等价因果对新增 V_Y 的三档噪声；四机制已知输入相对隐藏输入；因果对已知输入相对隐藏输入。报告 Bonferroni 八重校正的99.375%分层配对聚类区间。实用门槛为至少5个百分点、区间下界为正且两批均正向。70%绝对分类准确率仅为描述性可行性参考。

V_U 测量实际作用力；它不能区分具有相同实际作用力的源头模型。为此另加源头 V_Y。精确等价对为“一阶传递的阶跃源”与“直接作用的平滑源”；另有消去 U 后的等价表达式控制，两者写法不同不能被观测或干预区分。

干预直接设定 Y 为27种随机化脉冲之一，不编辑 X。对照在完全相同主动 X 上比较“知道输入”与“将输入协议作为未知量边缘化”。这是机制辨别，不将主动输入的响应报警说成未知故障预警。

机制分类主要用完整25时间单位观测，属于事后辨别；仅 X 的15时间单位结果单列。实时 M3/GLR 仍只用当前和过去 X，独立整轨迹5%目标误报校准。增加传感器只影响分类实验，不改变这两个报警器，因此不声称已经证明传感器增强预警。
