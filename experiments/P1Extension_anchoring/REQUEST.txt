# 二、逐项看实验结果：哪些达到了预期，哪些没有？

我进一步核对了 GitHub 中的完整 `REPORT.md`、预注册 `PROTOCOL.json` 和 `P2_DECISION.json`。下面的判断以这三个文件为依据。

## 1. P0：隐藏信息可恢复性——基本达到预期

阶段目标完成

P0 原本要回答：

单变量 X 是否包含足够的隐藏状态信息？哪些条件下可以恢复 Y、Z？

实验结果很清楚。

| 指标               | 信息较强  | 基础条件  | 信息较弱  |
| ---------------- | ----- | ----- | ----- |
| Oracle 恢复 Y 的相关性 | 0.849 | 0.416 | 0.003 |
| Oracle 恢复 Z 的相关性 | 0.973 | 0.807 | 0.096 |

这里 Oracle 指知道真实方程和参数，但仍然只观测 X 的实时滤波器。

这组结果有三个重要意义。

第一，单变量观测并不是完全没有用。

在信息较强的条件下，Y、Z 都能从 X 中得到较好的恢复。

这证明你的研究前提在一定条件下成立。

第二，隐藏状态的可恢复性具有明显的条件性。

例如，信息较弱时，Y 的相关性只有 0.003。

即使知道真实方程，也无法从当前及历史 X 中有效恢复实时 Y。

这不是神经网络能力不足，而是观测信息本身不足。

第三，延迟是一个非常重要的因素。

报告显示，每条因果边的延迟从 1 步增加到 3 步时，Oracle 对 Y 的恢复相关性从约 0.416 降至 0.176（对应报告中的延迟扫描）。

这意味着上游状态发生变化后，信息还需要经过传递过程才能到达 X。

所以，你原来提出的：

> 上游变化能否在下游预测失效之前被发现？

现在有了一个更明确的前提：必须先研究上游信息到达下游观测端的时间和信息损失。

### 但 P0 还没有证明什么？

它没有证明未知参数模型能恢复真实 Y、Z。

因为 Oracle 知道真实方程，而你的实际模型不知道。

这两者之间的差距，恰好就是 P1 要解决的问题。

## 2. P1：概率状态估计——没有达到预期

尚未通过

这是本轮最重要的失败结果。

你希望模型不只是输出一个 Y、Z 的估计值，还能够输出可信的概率分布。

例如：

\\[ Y_t\mid X\_{1:t}\sim N(\mu_Y,\sigma_Y^2) \\]

不仅要让均值接近真实 Y，还要让模型给出的不确定性符合真实误差。

但实验发现：

| 条件         | Y 的90%覆盖率 | Z 的90%覆盖率 | 联合90%覆盖率 |
| ---------- | --------- | --------- | -------- |
| 基础条件       | 81.45%    | 65.86%    | 67.98%   |
| 信息较强       | 54.04%    | 35.50%    | 35.76%   |
| 信息较弱       | 95.00%    | 82.37%    | 85.62%   |
| Oracle基础条件 | 90.00%    | 90.00%    | 89.96%   |
| Oracle较强条件 | 90.08%    | 90.06%    | 90.08%   |

这里需要特别注意一个容易误解的地方：

信息较弱条件下，覆盖率反而比较高，不代表模型恢复得更好。

因为模型可能给出很宽的概率区间。

例如，模型不知道 Y 到底是多少，就给出一个很大的范围，那么真实 Y 很容易落在范围内。

所以还必须结合：

- 相关性。
- MSE。
- 区间宽度。
- 联合负对数密度。
- CRPS。
- 概率校准。

综合判断。

报告中的联合负对数密度也说明了这一点：

| 条件   | 未知参数模型 | Oracle | 差距    |
| ---- | ------ | ------ | ----- |
| 基础   | 4.473  | 3.558  | 0.915 |
| 信息较强 | 9.931  | 3.759  | 6.172 |

信息较强条件下，模型虽然拥有较多可利用的信息，但反而出现了严重的概率失准。

这不是简单的模型预测精度问题。

## 3. 最重要的发现：X 预测准确，不代表隐藏因果链恢复准确

重要科学发现

我认为这是整轮实验最值得保留的结果。

报告中的下一步 X 预测结果：

| 方法         | X预测MSE   | X预测负对数密度 | 90%覆盖  |
| ---------- | -------- | -------- | ------ |
| 未知结构AR     | 0.767251 | 1.260982 | 90.01% |
| 未知参数链模型    | 0.767213 | 1.260958 | 90.01% |
| 真实参数Oracle | 0.767189 | 1.260944 | 90.00% |

可以看到，三种方法几乎一样。

但是隐藏状态恢复结果差距很大。

这意味着：

模型完全可能找到一套机制，能够很好地预测 X，却无法正确解释真实的 Y、Z。

我用一个简单例子解释。

假设真实系统是：

真实系统

Y：上游隐藏状态

Z：中间隐藏状态

X：唯一观测变量

但模型可能找到另一套隐藏机制：

模型学到的另一种解释

Y'：模型内部状态

Z'：模型内部状态

X：几乎完全相同的预测结果

模型内部的 Y'、Z' 不一定是真实 Y、Z。

报告甚至构造了两套不同参数：

- X 的下一步预测均值最大差异约为 \\(7.1\times10^{-15}\\)。
- X 的序列对数似然差异约为 \\(2.3\times10^{-13}\\)。
- 但 Y、Z 的后验均值却明显不同。

这说明不是单纯增加训练数据、网络层数就一定能够解决的问题。

你遇到的是可识别性问题，而不仅仅是模型性能问题。

# 四、能不能进行下一步？能，但我建议先做 P1-Extension

建议继续推进

我不建议停止课题，也不建议直接进入原来的 P2。

我建议下一轮研究一个明确的问题：

增加什么最少的、可验证的约束，才能让模型从多个等价的隐藏机制中识别出真实的 Y、Z？

这是目前最值得做的实验。

## 1. 先解决两个不可识别问题

根据报告，目前至少有两个问题。

问题 A：隐藏状态的身份不唯一。

不同的 \\(a,b,c,\alpha,\beta\\) 组合，可以产生相同的 X 分布。

模型不知道哪套参数才是实际系统的物理机制。

问题 B：真实传递延迟不唯一。

在本轮平稳高斯串联系统中，纯传递延迟只改变频域相位，不改变 X 的功率谱。

因此，单纯根据平稳 X 的概率分布，无法确定真实延迟。

这两个问题需要分别解决，不能只增加一个普通的正则化项就认为解决了。

## 2. 下一轮设计四种锚定实验

我建议先建立一个 P1-Extension，逐个检验以下条件。

A：时间尺度约束

优先测试

利用独立领域知识，约束 Y、Z、X 的时间尺度顺序。

例如已知上游 Y 的变化比 Z 更慢，而 X 的响应更快。

检验：这种约束能否排除交换隐藏动态角色的等价解释？

B：已知参数锚点

独立测量一个可信的系统参数，例如某个状态的时间常数或创新方差。

检验：固定一个参数后，是否能够缩小等价参数集合？

C：已知外部输入

对 Y 施加一个已知时间和幅度的外部输入，但模型仍然只观测 X。

检验：已知输入经过隐藏因果链到达 X 的响应，能否帮助确定因果方向和传递延迟？

D：稀疏辅助观测

平时只观测 X，但在少数时间点获得 Y 或 Z 的真实测量。

检验：少量锚定数据能否帮助恢复其余时刻的隐藏状态？

注意：这属于单变量连续观测加稀疏辅助测量，不再是严格意义上的纯 X-only。

这里特别强调：这些只是候选约束，不能预先假定它们一定有效。

每增加一个约束，都要先做数学上的可识别性审计，再训练模型。

## 3. P1-Extension 具体如何比较？

我建议设置五组实验：

| 组别 | 模型知道什么         |
| -- | -------------- |
| E0 | 只观测 X，原始未知参数模型 |
| E1 | X＋已知时间尺度顺序     |
| E2 | X＋一个独立测量的参数锚点  |
| E3 | X＋已知外部输入       |
| E4 | X＋少量辅助状态观测     |

所有模型都保留相同的测试轨迹。

评价指标仍然使用：

- Y、Z 恢复相关性和 MSE。
- 90% 边际覆盖率。
- 90% 联合覆盖率。
- 联合负对数密度。
- PIT 校准。
- 真实延迟识别率。
- 等价参数集合的大小。

最重要的是增加一项：

等价机制排除实验。

也就是说，不只是看模型恢复得好不好，还要检查：

是否还存在另一套不同的 Y、Z、参数和延迟，同样能够解释观测到的 X？

如果仍然存在，就不能宣称真实隐藏因果链已经恢复。

# 五、P1-Extension 成功后，才能进入真正的 P2

下一阶段完整研究路线

1. P1-Extension：解决隐藏状态身份与延迟锚定

   找到至少一种有效的可验证约束。
2. P2：上游状态变化检测

   在 Y 突变、渐变时，检验能否从 X 提前推断上游状态变化。
3. P3：动态因果连接变化检测

   Y、Z 正常，但 Y→Z 或 Z→X 的作用强度发生变化时，能否识别？
4. P4：预测失效提前预警

   将隐藏状态和因果连接的概率变化结合，预测未来 X 的失效风险。

最终需要比较两种时间：

\\[ T\_{\text{warning}} \\]

模型发出预警的时间。

\\[ T\_{\text{failure}} \\]

下游预测真正失效的时间。

提前量：

\\[ \Delta T=T\_{\text{failure}}-T\_{\text{warning}} \\]

只有在误报率受控的情况下，\\(\Delta T\\) 仍然显著为正，才有资格说明模型实现了提前预警。

# 六、还有一条备用路线：如果无法恢复真实 Y、Z 怎么办？

我不希望你的整个课题因为隐藏状态不可识别而停下来。

报告已经发现，未知结构 AR 对 X 的预测与 Oracle 几乎一致。

因此还有一条路线：

不再强求恢复真实物理 Y、Z，而是直接研究 X 历史中可识别的预测充分状态。

例如：

\\[ S_t=f(X\_{1:t}) \\]

然后：

\\[ P(X\_{t+h}\mid S_t) \\]

进一步预测：

\\[ P(\text{未来预测失效}\mid S_t) \\]

这样可以研究提前预警，但需要改变科学主张：

- 可以说恢复了预测相关的潜在状态。
- 可以说发现了预测风险的动态变化。
- 不能直接说恢复了真实的 Y→Z→X 物理因果链。
- 不能仅凭预测风险变化就声称发现了因果连接失效。

这是一条独立的研究路线，不应该和物理因果链恢复混在一起。
