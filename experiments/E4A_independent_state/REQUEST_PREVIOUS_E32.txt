可以。我认为**Yang 的论文很适合借鉴到你下一步的实验中，尤其是解决“新状态究竟应该增加、拆分，还是合并”这个问题。**

但需要先明确：我们不是直接照搬 Yang 的模型，而是把它的因果关系比较和漂移解释思想，改造成适用于你当前 E3 的概率化隐藏状态发现方法。

我建议将下一轮实验命名为：

# **E3.2：借鉴 Yang 的因果关系变化分析，实现概率隐藏状态的增加、拆分与合并**

## **一、Yang 这篇论文究竟有什么可以借鉴？**

你之前研究的 Yang 论文是：

*Detecting and rationalizing concept drift: A feature-level approach for understanding cause–effect relationships in dynamic environments*，2025 年，发表在 *Expert Systems with Applications*。

论文提出了 CDDRM（Causal Drift Detection and Rationalization Method）。

它的核心思路是：

**不只是判断数据有没有变化，还要比较变化前后的因果关系，判断究竟是哪种关系发生了变化。**

作者主要使用 NOTEARS 学习不同数据批次的因果图，再比较因果结构和关系强度，并将变化分为四类。

[image](https://www.google.com/s2/favicons?domain=https://www.sciencedirect.com\&sz=32)

sciencedirect.com+1



| Yang 的变化类型 | 通俗解释               |
| ---------- | ------------------ |
| Type 1     | 原来存在的因果关系消失了       |
| Type 2     | 原来不存在的因果关系出现了      |
| Type 3     | 因果关系没有消失，但重要程度发生变化 |
| Type 4     | 因果关系还存在，但作用强度发生变化  |

例如，原来：

\\[ A\rightarrow B,\quad C\rightarrow B \\]

后来变成：

\\[ A\rightarrow B \\]

说明原来 C 对 B 的作用关系消失了。

又例如：

\\[ A\rightarrow B \\]

后来变成：

\\[ A\rightarrow B,\quad C\rightarrow B \\]

说明出现了新的作用关系。

这给你的启发是：

**我们能不能把模型学习到的隐藏状态看作一组候选节点，然后比较不同状态组合下的动态关系，判断应该增加、拆分还是合并状态？**

我认为可以尝试。

但有一个重要区别：

Yang 研究的是已有特征及结果之间的关系变化，并不是从一个隐藏状态中自动发现新的物理变量，也没有直接提出概率隐藏状态的拆分、合并算法。

因此，下面是对其思想的研究性扩展，不是 Yang 原论文已经验证过的方法。

## **二、把 Yang 的思想改造成你的研究方法**

你现在的模型只观察 X，学习出：

\\[ X\rightarrow W_1,W_2 \\]

这些 W 不一定是真实物理变量，只是概率化的候选隐藏状态。

假设模型继续从 W1 中发现一个新状态：

\\[ W_1\rightarrow W_y \\]

此时不能立即把 Wy 加入模型。

我们要做的是：比较加入 Wy 前后，整个隐藏状态系统的关系发生了什么变化。

我建议把这个过程设计成四种判断。

## **四种隐藏状态结构判断**

情况 A：增加新状态

**Wy 是原来没有发现的独立动态信息。**

原来：

\\[ X\rightarrow W_1,W_2 \\]

新发现：

\\[ X\rightarrow W_1,W_2,W_y \\]

如果 Wy 在原始 X 中有独立的概率预测证据，而且经过独立测试仍然成立，就考虑增加。

情况 B：拆分状态

**Wy 原本混合在 W1 里面。**

原来：

\\[ X\rightarrow W_1 \\]

深入分析后发现 W1 实际包含两种不同的动态信息：

\\[ W_1\Rightarrow W\_{1a},W\_{1b} \\]

如果拆分后两种状态能够分别得到独立支持，就考虑拆分。

情况 C：合并状态

**Wy 与 W2 实际上表达重复的信息。**

原来：

\\[ X\rightarrow W_1,W_2,W_y \\]

如果 Wy 与 W2 在条件预测贡献、动态响应和跨种子表现上高度重复，就考虑合并。

情况 D：拒绝判断

**现有 X 不足以判断它们是否独立。**

不强行增加、不强行合并，也不强行拆分。

保留多个概率解释，等待更多观测证据。

这里我特别建议增加第四种情况。

因为未知系统可能本来就无法从 X 唯一区分不同隐藏结构。不能为了让模型输出一个明确结果，就强行做结构判断。

## **三、具体怎么做实验？**

我建议不要马上把所有结构变化放进一个大实验，而是设计四个连续子实验。

### **E3.2-A：新状态增加实验**

**研究问题：从 W1 中发现的新状态 Wy，究竟是不是 X 中原来没有充分利用的独立信息？**

例如，模型最初从 X 学到：

\\[ q(W_1,W_2\mid X\_{1:t}) \\]

之后从 W1 的概率历史中发现：

\\[ q(W_y\mid W_1,X\_{1:t}) \\]

注意，这里不是把 W1 和 Wy 当作两个确定数值，而是保留它们的联合概率分布：

\\[ q(W_1,W_2,W_y\mid X\_{1:t}) \\]

接下来做三项检查。

**第一项：检查 Wy 能不能解释新的 X 信息。**

比较两个预测模型：

\\[ M_0: P(X\_{t+1:t+h}\mid X\_{1:t},W_1,W_2) \\]

\\[ M_1: P(X\_{t+1:t+h}\mid X\_{1:t},W_1,W_2,W_y) \\]

用后续真实观测 X 计算联合负对数似然 NLL 和 CRPS。

如果 M1 在独立测试数据中稳定优于 M0，说明 Wy 提供了额外的预测信息。

但这还不够。

**第二项：检查 Wy 是否真的独立。**

例如，假设：

\\[ W_y=0.9W_2+\epsilon \\]

那么 Wy 虽然可能提高预测表现，却可能只是 W2 的另一种表示。

因此，还要比较：

- Wy 对 X 的独立条件预测贡献；
- Wy 与已有状态的条件依赖；
- Wy 在不同训练种子中的稳定性；
- Wy 在不同时间区间中的动态特征。

**第三项：使用 Yang 的关系比较思路。**

把增加 Wy 前后的候选状态关系图进行比较。

例如：

**增加之前**

W1

W2

**增加之后**

W1

W2

Wy

检查新增节点是否形成稳定、独立的动态关系

如果新增状态在多个独立数据批次中都能得到支持，并且增加后有稳定的预测收益，就允许它进入下一轮模型。

这里借鉴 Yang 的 Type 2 思想：原先没有识别到的关系或节点作用现在得到支持。

但要注意，Yang 的 Type 2 指的是新因果关系出现，不等于新隐藏变量出现。我们只是借用其比较前后结构的思路。

### **E3.2-B：混合状态拆分实验**

**研究问题：一个已经发现的 W1，是否把两种不同的动态信息混在了一起？**

假设：

\\[ W_1=f(U,V) \\]

模型最初只能得到一个综合状态 W1。

深入学习后，发现：

\\[ W\_{1a},W\_{1b} \\]

两个候选方向。

这次需要比较：

| 方案   | 概率状态表示                                |
| ---- | ------------------------------------- |
| 不拆分  | \\(q(W_1\mid X\_{1:t})\\)             |
| 拆成两个 | \\(q(W\_{1a},W\_{1b}\mid X\_{1:t})\\) |

拆分后重点验证：

1. 两个状态是否有各自独立的预测贡献？
2. 两个状态是否存在不同的动态持续性？
3. 两个状态是否具有不同的条件响应？
4. 两个状态能否在不同训练种子中重复出现？
5. 两个状态联合起来，能否比原 W1 更好地解释未来 X？

这里有一个非常重要的设计：

**不能因为两个拆分状态的相关性比较低，就认为它们一定是两个真实隐藏变量。**

例如，同一个真实状态 Y 可以被模型拆成一个缓慢变化分量和一个快速变化分量。

所以还需要进行单隐藏系统的负对照，专门检验模型是否把一个真实状态错误拆成两个。

### **E3.2-C：重复状态合并实验**

**研究问题：新发现的 Wy 是否只是原来 W2 的重复表示？**

例如：

\\[ q(W_2,W_y\mid X\_{1:t}) \\]

模型认为有两个状态。

但进一步检查发现，二者的动态预测作用几乎一致。

我们比较：

\\[ M_1=q(W_1,W_2,W_y\mid X) \\]

与：

\\[ M_2=q(W_1,W_2\mid X) \\]

如果删除 Wy 后：

- 独立测试 NLL 没有实质性恶化；
- CRPS 没有实质性恶化；
- 状态之间的预测贡献高度重叠；
- 合并后模型在不同种子中更加稳定；

就可以考虑合并。

这里借鉴 Yang 的 Type 1、Type 3 和 Type 4 的比较思想：

- 原有关系是否消失；
- 关系的重要性是否变化；
- 关系强度是否变化。

不过，合并状态不应仅凭某条关系消失来决定，而要综合概率预测和冗余证据。

### **E3.2-D：结构判断综合实验**

最后将三种操作放进同一个模型：

\\[ \text{发现候选状态} \rightarrow \text{概率联合更新} \rightarrow \text{结构关系比较} \rightarrow \text{增加、拆分、合并或拒判} \\]

模型每次得到新的 X 后，都更新：

\\[ q(W_1,W_2,\ldots,W_k\mid X\_{1:t}) \\]

当发现新的动态信息时，不立即修改结构，而是保留候选结构的概率权重。

例如：

| 候选结构       | 当前概率 |
| ---------- | ---- |
| 保留 W1、W2   | 35%  |
| 增加 Wy      | 45%  |
| 合并 Wy 和 W2 | 20%  |

这些是示意数字。

之后新 X 到达，模型计算各个候选结构对新观测的预测似然，再更新它们的概率。

这样，你最初提出的两条路线就真正结合起来了：

- 一条负责继续寻找新的隐藏信息；
- 另一条负责利用 X 验证这些信息；
- 概率更新负责调整不同结构解释的可信程度。

## **四、实验数据应该怎样设计？**

这里必须继续保持你最重要的研究前提：

**模型不知道真实系统中存在几个隐藏变量，也不知道真实因果结构。**

建议设置五类模拟系统。

| 数据组 | 实际隐藏结构          | 检验目标          |
| --- | --------------- | ------------- |
| S0  | 无独立隐藏状态         | 能否避免错误增加      |
| S1  | 一个隐藏状态          | 能否避免错误拆分      |
| S2  | 两个独立隐藏状态        | 能否发现新状态       |
| S3  | 两个高度相关的隐藏状态     | 能否区分独立信息和重复信息 |
| S4  | 不同隐藏结构产生相同 X 分布 | 能否正确拒绝判断      |

S0～S4 的真实结构和参数由实验生成程序保存，但不提供给模型。

所有训练、结构选择和在线更新只能使用 X。

真实隐藏变量只在模型冻结后用于最终评价。

### **建议的实验规模**

| 项目     | 建议              |
| ------ | --------------- |
| 每种系统条件 | 20个独立种子起步       |
| 训练轨迹   | 每种条件1000条       |
| 验证轨迹   | 每种条件200条        |
| 独立测试轨迹 | 每种条件200条        |
| 时间长度   | 沿用 E3，并增加长短序列对照 |
| 概率表示   | 完整协方差联合高斯起步     |
| 训练输入   | 仅 X             |
| 真实状态   | 冻结后评价           |

为了避免偶然结果，后续可以将种子扩大到30～50个。

## **五、怎么把 Yang 的四类关系变化，转化成你的增加、拆分、合并判断？**

这是我认为最值得设计的部分。

我们可以建立一个对应关系：

| Yang 的思想         | 你的隐藏状态研究           | 用来判断什么      |
| ---------------- | ------------------ | ----------- |
| Type 1：原有关系消失    | 某个候选状态的关系贡献消失      | 是否应该删除或合并   |
| Type 2：新关系出现     | 新候选状态与已有状态形成新的稳定关系 | 是否应该增加      |
| Type 3：原有关系重要性变化 | 某个状态的独立预测贡献发生变化    | 是否应该保留或重新评估 |
| Type 4：关系强度变化    | 状态之间的动态作用强度发生变化    | 是否需要调整状态结构  |

但这里要做一个重要改进：

Yang 比较的是不同数据批次中的关系变化。我们还需要比较**不同隐藏状态结构假设下的关系变化**。

例如：

- 模型 A：只有 W1；
- 模型 B：W1 拆成 W1a、W1b；
- 模型 C：W1 之外增加 Wy；
- 模型 D：Wy 与 W2 合并。

然后使用相同的 X 数据，比较这些结构解释。

### **具体的关系比较方法**

建议采用两个层次。

**第一层：概率状态之间的关系。**

从联合后验分布中抽取状态样本，而不是直接使用均值作为确定变量。

例如：

\\[ (W_1^{(s)},W_2^{(s)},W_y^{(s)}) \sim q(W_1,W_2,W_y\mid X) \\]

在每个后验样本上计算滞后依赖、条件预测贡献及候选图结构。

对不同样本重复计算，得到每条候选边的概率：

\\[ P(W_i\rightarrow W_j\mid X) \\]

注意，这里的概率首先代表模型和假设条件下的候选关系可信度，不应直接称为真实因果关系的概率。

**第二层：不同时间批次的关系比较。**

借鉴 Yang 的做法，把 X 分成多个连续时间批次。

例如：

| 时间批次 | 数据     | 研究目的      |
| ---- | ------ | --------- |
| B1   | 早期 X   | 初始状态结构    |
| B2   | 中期 X   | 新状态是否出现   |
| B3   | 后期 X   | 状态关系是否稳定  |
| B4   | 独立测试 X | 验证结构是否可重复 |

每个批次都重新进行概率状态推断和关系分析。

最后比较：

\\[ G\_{B1},G\_{B2},G\_{B3} \\]

如果新增状态只在某个批次出现，随后就消失，那么可能是暂时的动态特征，而不是稳定的独立隐藏状态。

如果它在不同批次、不同训练种子中都能得到支持，才值得进一步保留。

对于时间序列，不能直接把普通 NOTEARS 的静态 DAG 当作动态因果图。建议使用滞后展开的图，例如：

\\[ W\_{1,t-1}\rightarrow W\_{y,t} \\]

\\[ W\_{y,t-1}\rightarrow X_t \\]

并检查模型是否满足相应的时间顺序和无环约束。

# **六、如何评价 E3.2 是否成功？**

这里我建议设置五个核心评价指标。

| 评价指标             | 检验内容              | 越好意味着       |
| ---------------- | ----------------- | ----------- |
| 状态维数识别准确率        | 能否正确判断独立状态数量      | 减少错误增加和错误合并 |
| 状态拆分准确率          | 能否识别真实的独立动态成分     | 减少错误拆分      |
| 状态合并准确率          | 能否识别重复表示          | 减少冗余状态      |
| 双线一致性            | 两条路线能否发现相同的观测动态信息 | 提高发现稳定性     |
| 未来 X 联合 NLL、CRPS | 结构调整后预测是否改善       | 证明调整具有实际价值  |

另外，我建议增加一个非常重要的评价：

**结构调整后的概率校准。**

例如模型认为某种候选结构有90%的概率，那么在大量独立重复实验中，具有类似概率的结构判断是否真的能够得到相应程度的验证支持？

但要注意：真实结构的概率校准只能在模拟实验中利用隐藏真值进行评价，未知真实系统中不能直接验证这一点。

最终还要同时报告：

- 结构调整错误率；
- 错误增加率；
- 错误拆分率；
- 错误合并率；
- 拒判率。

不能为了提高识别率而让模型强行给出结构答案。

# **七、这一步实验与后续因果预警有什么关系？**

你的整个课题可以形成下面的递进关系：

**E3：概率化隐藏状态发现**

从 X 中学习 W1、W2，递进发现 Wy，并通过在线概率更新改善预测。

已完成原型

**E3.2：借鉴 Yang 的关系比较思想**

研究哪些状态应该增加、拆分、合并，以及什么时候不能判断。

下一步实验

**E4：隐藏因果结构识别**

在可识别条件下，研究候选状态之间的直接、间接作用，估计因果强度和作用范围。

**E5：动态因果失效提前预警**

监测上游状态、因果连接和作用强度的变化，检验是否早于预测失效报警。

需要强调，E3.2 成功不等于 E4 一定成功。它解决的是隐藏状态结构的可靠性，因果方向还需要额外的可识别条件。

## **八、我对这次改进的最终建议**

我认为可以借鉴 Yang，但不要把下一步实验变成简单的 NOTEARS 因果图学习。

因为你和 Yang 的研究对象有本质区别：

| 对比   | Yang            | 你的研究             |
| ---- | --------------- | ---------------- |
| 输入   | 已有数据特征及结果       | 只有 X             |
| 节点   | 已有观测特征          | 未知数量的概率隐藏状态      |
| 主要任务 | 比较不同阶段的因果关系     | 发现、增加、拆分、合并隐藏状态  |
| 核心方法 | NOTEARS 等因果发现方法 | 概率状态发现＋在线更新＋关系比较 |
| 最终目标 | 解释概念漂移          | 隐藏因果机制识别及失效预警    |

Yang 的论文可以作为关系比较、结构变化分类和漂移解释的参考，但不能作为隐藏状态身份已经可识别的依据。
