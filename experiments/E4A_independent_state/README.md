# E4-A：概率化双线隐藏动态发现

已完成E4-A1／A2／A3；这是受限线性高斯原型，不是一般未知系统的唯一因果结构发现器。20个条件×20个随机种子，1000／5000两个嵌套长度，800个模型组合，两批独立测试各80000行指标。训练和确认只读X，预测测试冻结后才开放隐藏真值。

**主要结论**：在线概率更新有效，递进提案没有证明相对完整直接提取的实用增益；独立隐藏因素发现门槛未通过。高相关系统中的物理状态区间失准，观测等价也阻止唯一物理身份判断。因此未进入E4-B／C，也未声称恢复因果链或实现失效预警。
