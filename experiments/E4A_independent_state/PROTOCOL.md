# E4-A 预注册协议：区分预测模式、长记忆与物理因素

2026-11-23。以最新E4附件末尾指令为准，只执行E4-A1/A2/A3。前一E3.2方案的关系比较思想保留为解释，不运行E4-B的ARD/Split-Merge，也不运行E4-C的PCMCI+、SCM或干预。Yang原文出版商与Crossref本环境均返回403；本轮不是CDDRM/NOTEARS复现，不把附件摘要当已核验原文结论。

## 数学边界与实际研究问题

模型参数冻结后，模型定义的状态均值、后验分布及独立随机抽样均由X历史和模型随机数产生。若条件包含同一完整X历史，不能要求它们再增加历史之外的外部信息。改用样本外联合预测差衡量相对受限W1摘要的表示增益，并与直接X历史概率模型比较；不将差值直接叫真实条件互信息或物理独立性证明。

区分物理因素数K、Markov存储维数d与可恢复的动态模式。单个U的AR2记忆需要d=2，但仍是一个因素候选。两AR1之和也有两个动态极点；它与单个ARMA(2,1)因素可具有完全相同的标量观测分布，因此不能以两个模式推断两个真实原因。

## 五类系统、每类四条件

A单AR1：U_t=r U_(t-1)+eps，X=U+epsX，U平稳方差s。基准(r=.9,s=1,R=.5)，三变体分别只改r=.99、R=2、s=.25。

B双独立AR1：U/V持续系数(a,b)，平稳方差(su,sv)，X=U+V+epsX。基准(.9,.4,1,1,.5)，三变体分别只改b=-.8、sv=.25、R=2。

C双高相关AR1：与B类似，但基准(a=.9,b=.85,su=sv=1,R=.5)，创新相关rho=.98；三变体只改rho=.999、b=.8、R=2。高度相关不作为重复或合并证据。创新协方差rho*sqrt(qu*qv)，不是人为将真状态直接泄漏给模型。

D单个长记忆因素：U_t=2r cos(omega)U_(t-1)-r² U_(t-2)+eps，X=U+epsX，创新方差使U平稳方差1。基准r=.97,omega=.15pi,R=.5；三变体只改r=.995、omega=.04pi、R=2。缓存U_(t-1)不算第二个物理因素。

E观测等价对：采用与B四条件相同参数、独立随机数据，每条X同时有两种真值解释：两个独立AR1，或单个W=U+V的长记忆ARMA21。X逐点相同；两个标签不是两条独立样本。

精确等价证书：phi1=a+b,phi2=-ab；g0=qu(1+b²)+qv(1+a²),g1=-(b*qu+a*qv)；sigma²=(g0+sqrt(g0²-4g1²))/2,theta=g1/sigma²。单ARMA为 W_t=phi1W_(t-1)+phi2W_(t-2)+e_t+theta e_(t-1)。用F=[[phi1,1],[phi2,0]],Q=sigma²*[1,theta][1,theta]^T,C=[1,0]验证其X自协方差和Kalman预测与双AR1完全相等。等价规则对所有拟合的双AR1解释应用，不能靠知道E标签才拒判。

## 规模与数据隔离

20条件×20种子4011..4030=400组合。主长度5000，短序列1000为同轨迹前缀；两种长度分别训练，不当独立复现。

每种子独立训练R20条、D20条，选择10条，确认A10条、确认B10条，测试A20条、B20条。每条生成5000步。40条训练轨迹总计20万时间点；使用较少长轨迹是可控首轮设计，最新附件未指定轨迹数。不是前一E3.2的1000条训练配置。

R/D训练严格独立；学习API仅接收X数组，case结构名不传入优化器。全部模型冻结后确认，确认冻结后两批测试。两批测试用同一冻结模型和独立轨迹，不能当两批独立训练。正式X预测冻结后，再生成额外20条审计轨迹用于状态读出（10条校准、10条评价）。真实状态和生成参数不用于训练、选择、确认或在线更新。

## 模型升级与拟合

概率候选族：观测AR1无潜在状态；一个AR1因素(d1)；一个AR2记忆因素(d2)；一个AR3记忆因素(d3)；两个独立AR1模式(d2)。所有潜在族采用X=Cz+epsilon，无额外自由观测AR系数，防止E3中观测AR与潜在记忆相互补偿。C采用贡献坐标规范（AR因素载荷1，记忆因素C=[1,0,...]），不是声称识别未知物理尺度。

因子数不预先指定，有限工作族的最大Markov容量3。模型是结构化线性高斯原型，不是一般未知系统的唯一真实分解。二AR1的独立创新是规范工作表示；不能用这一建模假设证明真实系统独立，C类用于检验这种失配。

直接路线从原始X自协方差/谱矩初始化，并以三个初值最多80次EM拟合，连续5次每步平均似然改善<1e-6可停止，记录未收敛与稳定性投影。递进路线先在R中选择单因素记忆解释，从完整后验FFBS路径（每提案2条）发现双模式初值；三组独立后验提案使用同样EM预算。不得只用后验均值。独立见证D从原始X单独拟合。无有效递进提案时记失败/待判，不偷偷用直接结果冒充递进。

所有组均保留完整滤波协方差，正式测试逐点先预测、评分再滤波更新。未来20步联合高斯预测积分状态不确定性。不同候选的预测解释权重用独立选择集预测似然与相同参数复杂度惩罚确定；在线使用逐点观测似然更新，无E3的强制0.01复位。它是固定估计参数下的解释权重，不是参数积分后的Bayes模型证据。完整证据/ARD属于尚未启动的E4-B。

保留四组消融：M1直接不更新、M2递进双线不更新、M3完整直接在线、M4递进双线在线。直接组=direct-R+direct-D，递进组=recursive-R+direct-D，训练数据预算一致。不更新组在200点前缀后停止测量更新，仍为概率分布，它只是消融。完整直接组不限制字典或状态容量，所有工作族和多初值均可使用。另保留AR40/200直接X历史概率参照，选择集决定阶数；它不是无限历史信息上界。

## 独立信息与稳定性

新候选相对选择集选定的最佳单因素记忆模型比较，而不只比较短期AR1。两条独立路线均需在确认A和确认B上改善联合20步NLL/步≥0.005，且种子内轨迹配对单侧检验通过预设多重比较，才能叫有稳定的新增预测证据。

双线功能对应使用相同候选模式的持续系数/预测响应形状，而非原始坐标相关。要求两实极点可分（间距≥.05），跨独立训练池最大匹配误差≤.05、20步标准化响应相关≥.95；近重根、宽后验或不匹配应拒判。另报告控制当前X与单因素预测后的候选预测增量残差相关，在确认A估计控制回归、确认B及独立测试评价，不用于真实状态身份命名。

后验不确定性报告条件方差、状态相关和概率区间宽度。时间段稳健性从训练早/晚两段分别计算原始X谱矩极点估计，作为同一X的重复检验，不能称独立物理观测视角。

## 评价与Go/No-Go

主预测指标为5000步条件下未来20步联合NLL/步；预测起点200,300,...且未来不越界，单步滤波每点执行。记录1/2/5/10/20联合NLL、边际CRPS、90%覆盖与区间宽度、MSE。按轨迹平均后按种子配对；主对照M3−M4、M1−M3、M2−M4及交互(M2−M4)−(M1−M3)四项Holm4，逐20条件Holm80；两测试批分别判定，95%种子块/轨迹bootstrap10000次，实用门槛0.005。

确认相邻/新增信息检验统一Holm：400组合×2长度×2确认块×2独立路线=3200项。规则冻结后不按测试最有利条件选模型。模态匹配与后验稳定性也须满足；不以显著的微小收益代替实用收益。

统计层Go参考：B中至少3/4条件的确认新增信息在≥16/20种子获得双路线重复支持；A、D错误新增不超过1/20/条件，并报告Wilson区间，20次不能证明真实误率≤5%。非等价模态解释能在独立测试中复现。E必须输出等价解释与拒绝唯一物理因素判断。

物理因素层Go必须有身份识别证据，不能将模态成功代替物理独立性。二AR1与单ARMA21等价时，物理解释在对应先验下保持不确定，拒判；模型不得利用系统名绕过该约束。因而允许“预测模式可恢复、物理因素未唯一识别”的分层No-Go结论。未满足附件的可靠物理区分目标，不启动E4-B/C。

状态评价分开：在模型冻结后，对A/B/D匹配工作族报告贡献坐标条件后验的相关、MSE、NLL/CRPS/90%覆盖（这是族条件诊断，不是自动选中真实物理族）；C报告独立创新假设失配，E报告两种等价解释。另用完全独立真值审计轨迹拟合线性读出并评价可恢复子空间，不把读出残差校准当真实Y/Z后验。可逆表示与物理变量身份分开。已知参数Kalman仅作封存后信息上界。
