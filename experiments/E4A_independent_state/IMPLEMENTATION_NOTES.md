# 实现前补充说明

- 只做最新附件的E4-A1/A2/A3。两个序列长度为嵌套前缀，不是800次独立系统种子；独立组合为400。
- 全部模拟与工作模型为零均值，学习器不研究未知常数/趋势。用自身训练X的RMS归一化，预测密度返回原单位，含正确Jacobian。不同训练池独立归一化。
- 单因素AR1/AR2/AR3分别用1/2/3个Markov存储坐标；双AR1用2个模式。后验协方差完整，独立过程创新不等于后验独立。物理因素数不由存储维数直接确定。
- 直接多初值均可使用整个原始X，不用受限字典。递进双模式仅由三组独立FFBS路径谱提案初始化，再以X重新联合估计；全无有效提案时登记失败，不挪用直接模型假装递进。其他单因素记忆模型与direct-R共用同一R拟合，独立见证始终是D池。
- 80次EM为各初值上限，阈值1e-6、连续5次停止，未收敛会报告。一个无关AR开发样本的全5000步模型组合耗时约14秒，正式拟合以三个进程执行。没有使用正式测试调预算。
- 权重是固定参数估计下的惩罚预测似然解释权重，非积分参数后的完整Bayes证据。E4-B的ARD和完整Split-Merge暂未实现。模型预测均为高斯混合，禁止将同一X的双路似然当独立物理证据相乘。
- 确认增量是新候选相对最佳单因素记忆解释的样本外概率增益，不是附件条件包含全部X历史时的严格Shannon互信息。直接历史参照只使用最近40/200点，非无限历史上界。
- 用单ARMA21等价证书解释双模式物理身份的不唯一。证书对所有已拟合双AR1模型适用，不依赖E系统标签。等价解释的先验映射相同才保证积分证据相同；本轮不冒称完成了这一积分估计。
