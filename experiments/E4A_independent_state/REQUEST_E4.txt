我建议把下一轮正式设计为 **E4：概率化隐藏状态发现、自动结构调整与因果关系识别实验**。

这次要针对 E3 暴露出来的问题进行方法升级，而不是简单增加训练次数或增加潜在维度。

最重要的是保留你一直强调的两个原则：

1. **未知系统：** 模型从头到尾只观测 X，不预先知道真实隐藏变量数量、真实变量身份和因果结构。
2. **双线并行：** 一条线从 X 中直接发现隐藏状态，另一条线从已有隐藏状态中递进发现新状态；两条线都使用概率分布表示，并且都根据新到达的 X 在线更新概率。

我会把实验分成 E4-A、E4-B、E4-C 三个部分。先验证隐藏状态能不能可靠区分，再验证增加、拆分、合并，最后验证因果关系。

# **一、E4 总体研究目标**

## **E4：未知系统下的概率化隐藏结构发现**

**唯一可观测数据：X 的连续时间序列**

训练、状态发现、概率更新均不使用真实隐藏状态

**直接发现线**

从 X 的历史直接学习多个概率状态

\\[ X\rightarrow W_1,W_2 \\]

**递进发现线**

从 W1 的概率后验中继续发现新状态

\\[ W_1\rightarrow W\_{1-y} \\]

**联合概率更新**

两条路线共同利用真实到达的 X 更新隐藏状态联合后验

**增加、拆分、合并、保留不确定性**

通过模型证据与独立测试决定结构变化

**动态因果结构识别与作用强度估计**

最终要回答五个问题：

- 从 X 中能否发现多个隐藏动态因素？
- 从 W1 中能否找到新的隐藏信息？
- 能否判断新信息是独立、重复还是混合？
- 能否自动调整隐藏状态数量？
- 能否进一步恢复隐藏状态之间的真实因果关系？

# **二、第一部分：E4-A——独立隐藏状态发现实验**

最高优先级

这是本轮最重要的实验。

## **1. 实验目的**

解决目前 E3 最核心的问题：

模型发现了 W1-y，但不知道它究竟是：

- 一个真实独立的新隐藏因素；
- W1 已经包含的信息；
- W1 中混合的另一个隐藏因素；
- 同一个隐藏因素在不同数学坐标下的表示。

这次要专门设计不同的真实系统，让模型在不知道真实结构的情况下进行识别。

## **2. 构造五类未知系统**

注意：下面的真实系统结构只由数据生成端掌握。模型端不允许看到这些结构。

| 系统 | 真实情况              | 主要检验的问题                 |
| -- | ----------------- | ----------------------- |
| A  | 只有一个隐藏因素 U        | 模型会不会错误拆分？              |
| B  | 两个相互独立的隐藏因素 U、V   | 能否发现真正的新状态？             |
| C  | 两个高度相关的隐藏因素 U、V   | 能否区分相关与重复？              |
| D  | 一个具有长记忆的隐藏因素 U    | 会不会把同一个因素的不同时间特征拆成两个状态？ |
| E  | 两个不同隐藏结构产生相同 X 分布 | 能否识别不可区分的情况？            |

这里特别强调 D 和 E。

**D 是为了防止模型把一个复杂的隐藏因素错误拆成多个因素；E 是为了检验模型是否知道自己的能力边界。**

## **3. 数据生成方式**

例如，系统 B 中，真实隐藏因素为：

\\[ U_t=0.8U\_{t-1}+\epsilon\_{u,t} \\]

\\[ V_t=0.5V\_{t-1}+\epsilon\_{v,t} \\]

观测端为：

\\[ X_t=0.7U_t+0.5V_t+\epsilon\_{x,t} \\]

模型只得到：

\\[ X_1,X_2,\ldots,X_T \\]

不知道 U、V，也不知道上面的方程。

为了避免模型只在某一组特殊参数下成功，需要改变：

- U、V 的持续性；
- U、V 对 X 的贡献强度；
- U、V 的相关程度；
- 观测噪声；
- 两个隐藏因素的时间尺度；
- 数据长度。

另外，E 类要专门构造观测等价的系统，不能只依靠增加噪声来假装不可识别。

## **4. 必须采用概率状态表示**

这次不允许再把 W1、W2 直接作为一个确定数值交给后续模块。

模型必须输出：

\\[ q(W\_{1,t},W\_{2,t}\mid X\_{1:t}) \\]

例如：

**某一时刻的隐藏状态联合后验（示意）**

| 状态解释 | W1  | W2  | 后验概率 |
| ---- | --- | --- | ---- |
| A    | 2.0 | 4.0 | 20%  |
| B    | 2.5 | 5.2 | 50%  |
| C    | 3.1 | 6.1 | 30%  |

实际模型应使用连续联合分布或混合分布，此表仅用于说明。

也就是说，模型不能直接认定 W1=2.5、W2=5.2。

它必须保留多种可能性，以及 W1、W2 之间的联合不确定性。

## **5. 双线并行具体怎么做？**

**第一条线：直接发现**

从 X 的历史中直接提取多个概率隐藏状态：

\\[ q_A(W_1,W_2\mid X\_{1:t}) \\]

**第二条线：递进发现**

从 W1 的概率后验及其历史中发现新状态：

\\[ q_B(W_1,W\_{1-y}\mid X\_{1:t}) \\]

**两条线共同进行概率更新**

新观测 \\(X\_{t+1}\\) 到达时：

\\[ q\_{t+1}(W)\propto P(X\_{t+1}\mid W,q_t)\\,q_t(W) \\]

实际实现中需要通过状态转移模型积分掉上一时刻状态，而不是简单把上一时刻的概率当作当前概率。

两条线各自预测未来 X，再使用真实到达的 X 计算观测似然，更新各自的联合后验。

这里有一个重要的技术要求：

**不能把从 X 得到的不同历史窗口当成天然独立的观测视角。**

它们仍然来自同一个 X。可以用不同时间尺度、不同预测任务构建多视角辅助验证，但不能把这种一致性直接当成真实物理变量独立性的证明。

## **6. 如何判断新状态是否真的独立？**

这次采用三种证据共同判断。

**第一：条件预测信息**

检验新状态是否提供了 W1 和 X 历史没有提供的额外信息：

\\[ I(W\_{1-y};X\_{\mathrm{future}}\mid W_1,X\_{\mathrm{history}}) \\]

如果在独立测试轨迹上仍然稳定大于零，说明它具有额外预测信息。

**第二：独立重复发现**

改变训练数据、随机种子和训练区间，重新从 X 中直接提取候选状态。

检查递进发现的 W1-y 是否能在另一条直接提取路径中找到对应的预测信息。

这里比较的是状态所携带的信息和预测功能，不是直接比较两个潜在变量的数值，因为潜变量可能存在旋转、缩放和标签交换。

**第三：后验不确定性**

检查新状态的后验是否稳定。

例如：

- 它的后验一直很宽，说明模型无法确定它的具体取值；
- 它与 W1 的后验高度依赖，但条件预测贡献接近零，可能是重复表示；
- 它有稳定的额外预测贡献，且在不同训练数据中重复出现，是保留它的更强证据。

但是，这三项证据仍然不能单独证明物理因果身份。最终要结合 E4-B 和 E4-C。

# **三、第二部分：E4-B——新状态增加、拆分和合并实验**

这一部分专门解决你最关心的结构调整问题。

## **1. 方法设计**

采用：

- ARD：自动相关性确定；
- Split-Merge：状态拆分与合并；
- 贝叶斯模型证据：比较不同结构的合理性。

不再固定隐藏状态数量。

例如初始模型得到：

\\[ W_1,W_2 \\]

随后递进模型发现 W1-y。

模型不直接决定增加，而是同时提出不同结构：

**候选结构 A：保持原状**

W1

W2

新信息没有足够独立证据，暂不调整。

**候选结构 B：增加状态**

W1

W2

W3

W1-y 提供独立的新信息，增加为 W3。

**候选结构 C：拆分状态**

W1-a

W1-b

W2

原 W1 中包含两个可以独立识别的动态因素。

**候选结构 D：合并状态**

W1 + W2

两个状态没有得到独立证据，合并后的模型更简洁且预测不受实质影响。

## **2. 如何比较四种结构？**

每种结构都需要重新计算完整的概率模型，而不是只比较某个隐藏状态的相关性。

主要采用：

\\[ \log P(X\_{\mathrm{test}}\mid M_k) \\]

以及模型证据：

\\[ P(X\mid M_k) = \int P(X\mid\theta_k,M_k) P(\theta_k\mid M_k)d\theta_k \\]

前者看模型对未见 X 的预测能力，后者考虑模型复杂度和参数不确定性。

两者应结合使用。

还要加入 ARD 的维度收缩机制，使不必要的状态逐渐失去作用。

## **3. 具体实验对照**

| 实验条件        | 预期正确操作      | 重点检验        |
| ----------- | ----------- | ----------- |
| 真实一个隐藏因素    | 保留一个        | 是否过度拆分      |
| 两个独立隐藏因素    | 增加或保留两个     | 是否漏掉新状态     |
| 两个高度相关因素    | 保留不确定性或识别两个 | 是否错误合并      |
| 一个长记忆因素     | 保留一个        | 是否把时间记忆当新变量 |
| 一个混合表示的两个因素 | 拆分          | 是否能够分离      |
| 两种结构观测等价    | 拒绝确定判断      | 是否承认不可识别    |

特别要注意：高度相关不等于应该合并。如果两个因素有独立的动态创新来源，模型仍然可能识别它们；如果观测信息不足，则应该保留不确定性。

## **4. 结构调整必须有防止反复变化的机制**

建议采用三个层次：

1. 候选状态出现：只登记，不立即增加。
2. 独立测试通过：进入待确认状态。
3. 在新的测试区间重复通过：正式增加、拆分或合并。

同时设置结构调整的复杂度惩罚和滞回机制，避免模型今天拆分、明天又合并。

# **四、第三部分：E4-C——隐藏状态之间的因果关系与作用强度实验**

前面两部分解决的是隐藏状态是否存在、结构是否合理。

这一部分才开始研究它们之间的因果关系。

## **1. 构造真实因果系统**

建议设计四种基础结构。

**结构 A：直接作用**

U

X

**结构 B：间接作用**

U

V

X

**结构 C：直接和间接作用同时存在**

U

X

U

V

X

**结构 D：共同驱动**

U

V

X

U 分别影响 V 和 X，不代表 V 导致 X。

四种结构都只向模型提供 X。

真实 U、V 只保存在数据生成端，实验结束后用于验证。

## **2. 学习动态因果结构**

采用两个阶段：

- PCMCI+：筛选隐藏状态之间可能存在的滞后因果关系。
- Dynamic SCM：对候选因果边建立结构方程，估计作用强度。

例如：

\\[ V_t=f_V(V\_{t-1},U\_{t-1})+\epsilon_V \\]

\\[ X_t=f_X(X\_{t-1},V\_{t-1})+\epsilon_X \\]

最终要估计：

\\[ U\rightarrow V\rightarrow X \\]

以及是否同时存在：

\\[ U\rightarrow X \\]

但必须强调：PCMCI+ 不能直接拿未知真实变量 U、V 运行。实际是先从 X 得到概率潜在状态，再在每个后验样本或联合后验上进行候选结构分析，并传播不确定性。

## **3. 必须加入干预验证**

这一部分是 E4-C 的核心。

数据生成端可以分别实施：

\\[ do(U_t=u_1) \\]

和

\\[ do(U_t=u_0) \\]

比较两种情况下 V 和 X 的变化。

同时对 V 进行干预：

\\[ do(V_t=v_1),\quad do(V_t=v_0) \\]

然后检查模型估计的作用方向和强度是否与真实干预效应一致。

特别是结构 D：

即使 V 与 X 高度相关，干预 V 后 X 不一定发生变化。

这可以检验模型是否把共同驱动误认为直接因果。

**这里的干预只在模拟真实系统中执行，模型训练和推断仍然只使用 X。** 如果现实中无法干预隐藏状态，就不能直接声称已经验证了真实物理因果关系。

# **五、整个 E4 的具体实验规模与数据安排**

建议先做可控规模的验证，不要一开始就把所有参数组合扩大到几百种。

## **1. 实验规模**

| 项目       | 建议设置      |
| -------- | --------- |
| 真实系统类型   | 5 类       |
| 每类参数条件   | 4 组       |
| 每个条件随机种子 | 20 个      |
| 每条轨迹长度   | 5000 个时间步 |
| 训练数据     | 独立训练轨迹    |
| 验证数据     | 独立验证轨迹    |
| 测试数据     | 独立测试轨迹    |
| 模型观测     | 只有 X      |
| 真实隐藏状态   | 只在最终评价时开放 |

E4-A、E4-B 可以共用同一批模拟系统，但必须在独立测试轨迹上进行最终评价。

E4-C 另外建立干预数据集，不允许将干预后的结果泄漏给模型训练。

每个条件 20 个种子是初步规模。如果结果接近判定边界，再增加到 50 个或更多种子。

## **2. 评价指标**

这次不能只看预测误差，因为预测得好不代表隐藏状态识别正确。

| 评价目标    | 指标          | 判断什么         |
| ------- | ----------- | ------------ |
| X 的概率预测 | NLL、CRPS    | 概率预测是否合理     |
| 概率可靠性   | 90%覆盖率、区间宽度 | 不确定性是否可信     |
| 隐藏状态恢复  | 后验相关、状态重构误差 | 是否恢复真实动态信息   |
| 独立状态发现  | 错误发现率、漏发现率  | 是否把重复信息当新状态  |
| 状态数量    | 维数识别准确率     | 是否正确决定隐藏状态数量 |
| 拆分与合并   | 结构操作准确率     | 是否正确调整状态     |
| 因果结构    | SHD、方向准确率   | 因果边是否正确      |
| 因果强度    | 系数误差、干预效应误差 | 作用大小是否准确     |

其中有两个特别重要的评价原则：

**第一，状态概率评价必须使用真实隐藏状态作为事后评价依据。**

例如真实系统中存在 U、V，实验结束后才能检查：

\\[ P(U_t,V_t\mid X\_{1:t}) \\]

是否覆盖真实 U、V。

这不违反未知系统设定，因为模型训练过程中没有接触 U、V。

**第二，必须考虑潜变量的等价表示。**

例如模型恢复了真实状态的旋转组合，预测能力很好，但坐标与 U、V 不一一对应。这种情况下不能直接按坐标相关性宣布失败或成功，而应分别评价可恢复的信息子空间和物理变量身份。

## **3. 必须进行四组方法消融**

这次尤其要判断概率更新和递进发现是否真的产生协同价值。

| 模型 | 直接发现 | 递进发现 | 在线概率更新 |
| -- | ---- | ---- | ------ |
| M1 | 是    | 否    | 否      |
| M2 | 是    | 是    | 否      |
| M3 | 是    | 否    | 是      |
| M4 | 是    | 是    | 是      |

M4 是你的完整方法。

比较 M4 和其他三个模型，才能判断：

- 递进发现是否有价值；
- 在线概率更新是否有价值；
- 两者同时运行是否有额外收益。

另外保留一个完整直接提取模型，作为重要的公平参照。不能故意限制直接模型的容量，否则无法证明递进方法具有优势。

# **六、实验成功标准：什么时候可以进入下一阶段？**

我建议设置明确的 Go/No-Go 标准。

**E4-A：独立隐藏状态发现**

必须先通过

- 双隐藏系统能够稳定发现额外信息。
- 单隐藏和长记忆系统的错误拆分率受到控制。
- 不同训练数据中候选信息具有可重复性。
- 不可识别系统能够保留不确定性。

**E4-B：增加、拆分、合并**

第二个门槛

- 真正独立的信息能够得到保留。
- 重复表示不会反复增加新状态。
- 混合状态能够在可识别条件下拆分。
- 不可识别情况下不强行判断。

**E4-C：因果关系恢复**

第三个门槛

- 直接和间接结构能够区分。
- 共同驱动不会轻易被误判为直接因果。
- 估计的作用方向与真实干预方向一致。
- 作用强度在独立数据上具有稳定精度。

如果 E4-A 不通过，不建议进入 E4-B 的正式结构调整实验。

如果 E4-B 不通过，也不建议直接把潜在状态之间的关系解释为真实因果图。

# **七、E4 完成之后，如何衔接你的最终课题？**

你的最终研究目标并不是单纯发现隐藏变量，而是因果失效提前预警。

因此 E4 后面还有两个阶段。

| 阶段 | 研究内容       | 核心问题                    |
| -- | ---------- | ----------------------- |
| E5 | 动态因果机制变化监测 | 隐藏状态之间的作用关系发生变化，模型能否发现？ |
| E6 | 因果失效提前预警   | 能否在预测性能明显下降前发出预警？       |

例如：

原系统：

\\[ Y\rightarrow Z\rightarrow X \\]

原来 Y 对 Z 的作用强度为：

\\[ \beta\_{YZ}=0.8 \\]

后来真实系统发生变化：

\\[ \beta\_{YZ}:0.8\rightarrow0.2 \\]

你希望模型只观察 X，就能逐渐发现：

- 上游隐藏状态的概率分布发生变化；
- Y 到 Z 的连接作用强度发生变化；
- Z 的后验预测开始偏离原有机制；
- X 的未来预测风险逐渐升高。
