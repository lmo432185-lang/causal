# L4 的已知候选集合与不可识别边界

本文件讨论预先指定的平稳线性高斯候选族，不依赖测试轨迹的真实标签。Y、Z不可观测且没有外部身份标定，两个潜在创新方差设为1只是各自单位的选择；结构系数和X过程／测量噪声均未知。

记 z=e^{-iω}，D_r=|1−rz|²。X自回归系数为b，过程创新方差q，测量噪声方差R。以下比较保留相同b和R；因此已经足以证明某些歧义，无需穷尽全部不同b的解释。

## 1. G2/G4 的隐变量名称置换

G2的状态矩阵为

```
[a, 0, 0]
[α, c, 0]
[0, β, b]
```

把Y/Z的坐标交换，得到G4的合法参数；观测行仍只读取X。两个潜在创新的单位协方差保持不变，X的完整有限维分布完全相同。对称的参数范围也保持不变。

因此，仅告诉模型候选变量叫Y和Z，并没有给它们提供可观测身份。G2与G4不仅在某些真参数下难以区分，而是整个未知参数族一一对应。多次独立初始化若给两族不同的最优分数，也只能说明优化误差，不能证明方向。

本轮G4使用四条G2 EM轨迹的精确置换；开发检验还独立执行了两边EM，确认更新等价。这防止将局部最优差异伪装成方向证据。

## 2. 两个独立直接原因也可能等价于串联

G1的输出谱为

```
S_X = [q + u²/D_a + v²/D_c]/D_b + R
```

假设a>c>0，可定义一个G2模型：

```
β² = v² + (c/a)u²
α² = u²(a−c)(1−ac)/(aβ²)
```

它的输出谱为

```
S_X = [q + β²/D_c + β²α²/(D_a D_c)]/D_b + R
```

两式分子系数逐项相等，且α、β为非负实数。若a<c，先交换G1的两个隐藏原因即可；G1的目标图不因这个交换而改变。a=c时退化到单一隐藏AR分量，可用边界模型表示。

因此，在参数自由且映射仍位于预先允许范围时，“两个独立直接原因”和“一个上游源经中间状态传递”可以对X完全等价。只有潜在变量数量或名称不足以排除该歧义。

反向映射并非总有非负解：某些串联谱不属于正权独立AR混合子族。故本结论不声称所有候选在所有参数下都一样，也不把一次未找到映射当成唯一性证明。

## 3. 一步混合路径的串联替代

G3的隐藏驱动力谱分子可以写作M−2L cosω，其中

```
L = β² a + u² c − uβα
M = u² + (βα−uc)² + β²(1+a²)
```

u为Y→X直接系数，β为Z→X系数。对r=a或c，若

```
L/r > 0
α_new² = M/(L/r) − 1 − r² >= 0
```

则以r作源持续性、另一极点作中间持续性，取β_new²=L/r即可构造相同X谱的串联模型。代码仅在参数范围合法且数值核验证通过时报告该替代，不读取任何真实隐藏答案。

## 4. 单纯隐藏传递延迟不一定进入X谱

纯链Y→Z→X中，把Y→Z滞后从1改成d，源贡献多一个z^{d−1}因子。独立创新、平稳且无直接Y→X路径时，该因子的模恒为1，X自谱不变。

因此本轮纯链候选使用delay=1的规范实现，并不能凭X确定真实隐藏延迟。缓冲状态只是复制历史值的计算状态，不是新增物理隐藏原因。Oracle看到Y/Z后，延迟才成为可检验的相对时间信息。

## 5. 混合相对延迟与未知X过程噪声的混淆

当Y→Z滞后为2且存在直接u路径，隐藏驱动力分子为

```
F0 + F1 cosω + F2 cos2ω
F0=u²(1+c²)+β²(1+a²+α²)
F1=−2[u²c+β²a+cuβα]
F2=2uβα
```

而D_aD_c的cos2ω系数为2ac。若X过程噪声未知，可先改变

```
q_new = q + F2/(2ac)
```

再从驱动力分子中减去相应的D_aD_c项，剩下只有常数与cosω项。在某些参数下，它又能用上节的纯链形式表示。

例如a=.8、c=.7、b=.5、u=.2、β=.4、α=.5、q=.25，都为合法正参数；存在另一个更大q、更强α、更小β的串联模型与其X谱完全相同。补充审查在揭晓真实答案前登记，数值协方差核误差约3.1×10⁻¹⁶。

因此，混合路径的相对相位可能改变观测谱，但未知过程噪声等自由参数有时能吸收这种变化。不能直接把“能看到延迟特征”升级为“唯一识别了中间环节”。

## 6. 何时才可以谈条件性识别？

必须区分：

1. 有限、受约束候选族在某些参数下给出不同X分布；
2. 有限样本是否有足够证据排除其他候选；
3. 外部真实系统是否确实属于该候选族、潜在名称是否有物理身份锚点。

缺少其中任何一项，都不能把较高预测评分当成唯一物理图。非负AR／系数范围、独立白创新、候选滞后范围都是本实验假设，不是由X自动认证的事实。

本轮进行有限次多起点广义EM，不能保证全局最优。数学上成立的置换／谱恒等式不依赖EM是否收敛；其他候选排除则仍受优化和样本误差影响。算法找到一个合法等价解释，足以否定唯一性；没有找到，不足以证明唯一性。
