# 运行前实现说明

- 新基础W1由训练似然＋BIC在已有单因素族中选择，避免先用选择集构造参数先验，再把同一选择似然重复计入。旧J0/M3仅保留旧权重作为封存算法对照。
- R2的新增状态初值来自先验创新的AR动态，R3从FFBS完整路径和创新过程的交叉矩产生全F/Q初值。所有代理量只用于初始化；E步对完整状态积分，X似然只使用一次。
- 原始递进R1历史双实极点规则保留；D类复杂极点的R1无效提案仍记录。R3可使用完整复杂动态后验路径，不要求先压成两个实极点。
- A/B分别含基础、obs、latent、dense四种预定结构，每结构2个bootstrap参数粒子，共8；E每结构取直接的一个与递进的另一个，共8。三组训练数据和粒子数量匹配。共同基础及obs拟合可以共享，不把重复计算当证据。
- 参数粒子来自整轨迹bootstrap，并在训练内估计原基础参数及新增参数；选择数据仅通过一次顺序似然更新离散经验先验。对该有限先验的积分精确；它不是对所有连续参数和所有未知结构的完整Bayes，不能提前保证物理覆盖。R3是后验路径／创新联合初始化下的共享状态模型，不是两个X证据相乘。
- C1报告允许相关Q的族及rho积分，C2为对角Q点；C3包括rho=0的规范点（与C2相同，明确标注），C4将4次训练bootstrap参数与17节点rho积分组合。另报告只传播可识别参数的对照，区分参数误差与不可识别方向；真实rho和oracle只在最终审计开放。
- 统一状态任意坐标与U/V不一一对应，U/V联合分数不作强行跨坐标比较；统一目标为S=aX前值＋CW的观测作用。额外独立读出仅事后评价，不把读出残差当物理后验。
- 所有负收益、无效候选、8粒子不足和24/12步未收敛均保留。有限预算可能限制数值优化，但不能将不可识别或无新增预测证据归咎于样本不足。
