# 冻结前的最终评价约定

- 主6对照、24条件Holm144保持不变；新增4个分解／完整强单线对照Holm4和Holm96，贝叶斯校准额外Holm12，原C16不变。10000次bootstrap。所有比较分别报告测试A/B。
- StrongestSingle仅用选择集在A、B、完整直接R0、原M3和原始X历史AR40/200中选择，不能测试后挑选。确认比较仍以R0同池强直接点模型为参照；不使用弱无更新模型制造收益。
- 所有失败与缺失保留并报告配对可用率，缺失不能计实用成功。候选确认未通过也可作为未确证假设参与原样测试，但不宣称独立因素已存在。
- J1/J2潜在坐标不同不计算伪造的U/V联合NLL，统一S作用目标与X概率评分；C贡献坐标模型才评分物理U/V。事后读出只评价信息，不反馈训练。
- 可信区域为精确有限混合分布的Rosenblatt区域；非矩匹配椭圆，也不冒称HPD。时间采样预定10点；所有时刻完整滤波。
- 连续参数Bayes为显式先验下精确高斯似然的MCMC；有限粒子经验Bayes为不同方法，二者不可混称。MCMC未达Rhat/ESS标准仍保留，不能宣称后验收敛。
- 从两链选8/16样本的敏感性诊断固定新C四条件种子4011，不按结果选择方法。rho17/33节点敏感性同一固定子集。不因敏感性较好就改主要粒子数。
- 先前/tmp模型丢失运行仅保留事故与原manifest，不作为有效结果或独立复现。报告依据重建且持久化的新480模型与全新stage10/11/12数据；主阈值、代码和训练X不改。

补充的机制比较家族：R1_original−R2、R1_original−R3、R1_aug−R2，整体Holm3／24条件Holm72；容量家族：基础none相对obs、direct_latent、direct_both、direct_dense，整体Holm4／24条件Holm96。均为预注册诊断家族，不可取代6项原主检验。所有新增比较在新确认和测试前冻结。

X未来20维联合覆盖用全高斯混合的条件Rosenblatt变换评价50/80/90/95%区域，未来向量的前缀只用于判断同一已发预测区域的成员关系，不重新发预测、不回流模型。这是可靠性描述，不能凭此单项宣布互补或物理身份成立。

固定积分敏感性阈值：90%覆盖差≤0.02、区间宽相对差≤10%、联合状态NLL差≤0.05仅作为数值稳定参考；超出时保留并明确近似误差，不据此重选主要粒子数。重放NLL绝对容差1e-8，极大MSE等量可采用另加1e-10相对容差，以匹配12位有效数字的归档精度。

预测可以定义与完整方案成功是两个不同状态。额外保存protocol_complete：若某方法缺失独立训练池或预定粒子，原始可用混合仍评分并保留，但不能计作完整方案的实用成功。旧M4的原始变维候选空间按旧规则保留，不把其允许的无效提案伪装成新缺失。不同失败类型在报告中分别计数。

C5单因素记忆强参照同时输出MEMORY_POINT（两独立训练池的基础记忆模型，选择X确定权重）。其共同S概率可比较，U/V联合密度仍不适用。物理校准主诊断只有5000设置；1000是共享测试的训练／选择前缀敏感性。
