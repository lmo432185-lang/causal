# 测试前概率评价实现补充

未读取本轮确认或测试；不改变0.005门槛、任何拟合、先验、种子或成功规则。

1. 状态概率指标在预定250,750,...4750共10个时刻取样，每条轨迹仍完整逐点滤波；不是只用这10点做推断。20测试轨迹×20种子=每条件4000个时刻，置信区间仍以训练种子／轨迹为独立块，不将4000点视作独立种子。
2. 二维联合覆盖采用U后V的Rosenblatt变换，将完整高斯混合后验映到两个标准正态，再用chi²二维球形成50/80/90/95%联合可信集合。这是真实混合分布下的联合区域，不是矩匹配高斯椭圆，也不称HPD最高密度集合。替代原协议“最高密度”措辞，避免昂贵且有噪声的逐点Monte Carlo阈值。变量次序固定不按效果挑选。
3. 对物理坐标不匹配的共享状态，U/V联合NLL记不适用。以同单位观测作用S=aX前值＋CW评分，另提供事后独立读出；不强行用读出映射制造物理后验。
4. 确认失败的候选仍可作为未确证模型假设参加比较；“后验中保留假设”不等于已确认新因素。确认只决定证据状态，不借测试删改假设或宣称结构调整已执行。
5. 有限粒子推断的结构集合预定为none/obs/latent/dense，不先用选择集选latent/both再重复计入同一选择证据。both保留为容量诊断。基础族在训练数据用BIC选择，因此参数经验先验不预先借用选择集证据。
6. R1_original对应原封存M4规范混合（J0同一方法），R1为增加状态形式的FFBS路径诊断，二者必须分别列示。R0额外保留旧完整直接工作族，直接基线的总搜索成本更高；新增候选每拟合3×24步、A5各8粒子预算相同。不得声称全流程CPU严格相等或已证明效率优势。
