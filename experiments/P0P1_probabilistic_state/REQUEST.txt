我建议你现在先不要急着再训练一个更复杂的神经网络。你之前的 L1、L2、L3 实验已经暴露出一个关键问题：

只观测 X 时，模型能够提取一些隐藏动态信息，但这些信息不足以稳定地区分 Y、Z，更不足以直接证明 Y→Z→X 这条因果链。

所以，下一步不能只是继续提高 Y、Z 的重构相关系数，而应该同时解决两个问题：

1. 信息问题： 单变量 X 中究竟包含多少关于 Y、Z 的信息？什么条件下这些信息足以支持恢复？
2. 预警问题： 即使不能准确恢复真实 Y、Z，能否利用它们的概率分布及传递关系，提前预测 X 将出现异常？

这两个问题要分开验证，最后再合并。

我认为你的课题仍然有研究价值，但需要把研究目标从“任何未知系统都能从一个 X 恢复完整因果链”，收缩为：

> 在明确的动力学假设和可识别条件下，研究单变量观测中的隐藏状态概率恢复、动态因果传播，以及基于概率传播的预测失效提前预警。

这个表述更科学，也更容易通过实验验证。

## 1. 最接近你的整体思路：Causal Discovery and Forecasting in Nonstationary Environments with State-Space Models

# 二、下一步究竟怎么做实验？我建议分成五个阶段

这里我不建议直接把所有想法放进一个模型。因为如果最终预警失败，你无法知道是隐藏状态没恢复出来、因果关系没识别出来，还是概率传播本身有问题。

建议按照下面的路线开展。

整体实验路线

1. P0：重新研究单变量可观测性

   找到 X 能恢复 Y、Z 的条件和信息上限。
2. P1：隐藏状态概率估计

   不只输出 Y、Z 的估计值，还输出它们的概率分布。
3. P2：动态因果关系概率传播

   检验 Y 的变化能否通过 Y→Z→X 的关系，提前预测下游状态变化。
4. P3：动态因果连接失效检测

   检验 Y、Z 没有异常，但因果连接本身发生变化时，模型能否发现。
5. P4：预测失效提前预警

   把隐藏状态、因果连接和概率传播结合起来，与传统预警方法比较。

## P0：重新研究 X 到底能提供多少隐藏信息

第一步，建议优先做

你之前 L1 的结果是：

- Z 重构相关性约 0.809。
- Y 重构相关性约 0.407。
- 两个潜在维度高度重复。

L2-A 又发现，即使知道真实方程，卡尔曼滤波也无法很好地实时恢复 Y。

因此，不能简单认为是编码器不够复杂。

### 实验怎么做？

继续使用：

\\[ Y\rightarrow Z\rightarrow X \\]

但这次系统地改变五个因素：

| 因素     | 实验条件         | 研究目的       |
| ------ | ------------ | ---------- |
| Y 的持续性 | 0.5、0.8、0.95 | 上游信息持续多久   |
| Y→Z 强度 | 0.2、0.5、0.8  | 上游作用是否容易传递 |
| Z→X 强度 | 0.2、0.5、0.8  | 下游是否容易观测   |
| X 观测噪声 | 低、中、高        | 噪声如何影响恢复   |
| 传递延迟   | 1、2、3 步      | 延迟是否造成信息丢失 |

每组使用独立模拟轨迹。

比较四种方法：

1. 当前 X。
2. L1 原编码器。
3. 线性高斯状态空间模型。
4. 已知真实参数的卡尔曼滤波。

另外保留卡尔曼平滑作为事后信息上限。

### 特别增加一个重要实验

不要只评价 Y 和 Z 的相关系数，还要评价：

\\[ P(Y_t,Z_t\mid X\_{1:t}) \\]

的概率质量是否覆盖真实状态。

例如，模型说：

Y 有 90% 的概率在 0.5～0.8 之间。

那么真实 Y 是否有接近 90% 的比例落在这个区间？

这样才能知道模型是否真正掌握了隐藏状态的不确定性，而不是仅仅给出一个看似准确的点估计。

P0 的目标不是一定要恢复 Y、Z，而是找到可恢复条件，并确定哪些条件下只能恢复组合状态。

## P1：建立隐藏状态概率估计模型

这一步才正式进入你的核心方法。

原来模型可能输出：

\\[ \hat Y_t=0.8 \\]

现在改成：

\\[ Y_t\mid X\_{1:t}\sim N(\mu_Y,\sigma_Y^2) \\]

同时：

\\[ Z_t\mid X\_{1:t}\sim N(\mu_Z,\sigma_Z^2) \\]

但更推荐联合估计：

\\[ P(Y_t,Z_t\mid X\_{1:t}) \\]

### 怎么做？

先假设模型知道系统可能存在两个隐藏状态，但不知道真实参数。

真实系统：

\\[ Y\_{t+1}=aY_t+\epsilon_Y \\]

\\[ Z\_{t+1}=bZ_t+\beta\_{YZ}Y_t+\epsilon_Z \\]

\\[ X\_{t+1}=cX_t+\beta\_{ZX}Z_t+\epsilon_X \\]

训练时：

- 只输入 X。
- 不输入 Y。
- 不输入 Z。
- 不告诉模型真实参数。

模型需要根据 X 学习状态转移规律和隐藏状态的概率分布。

可以使用粒子滤波、变分状态空间模型作为候选实现方法。

但需要特别强调：这一步仍然需要结构约束、尺度约束和可识别性假设。不能让模型任意旋转潜在变量，再把它们直接称为 Y、Z。

### 如何评价？

训练完成后，才用真实 Y、Z 进行独立评价：

- Y、Z 的恢复误差。
- 真实值是否落在预测置信区间内。
- 不同时间点的概率校准。
- Y、Z 能否被区分。
- 与 P0 理论参照的差距。

如果 P1 连隐藏状态概率都不能可靠估计，就暂时不进入 P2。

## P2：验证你最重要的创新——概率传播能不能提前发现下游变化？

最值得重点研究

这是你整个想法中最有潜力的部分。

### 实验设置

构造：

\\[ Y\rightarrow Z\rightarrow X \\]

让 Y 在第 300 个时间点发生变化。

例如：

\\[ Y:0.2\rightarrow0.8 \\]

但是：

\\[ \beta\_{YZ},\beta\_{ZX} \\]

保持不变。

真实系统中，Y 先发生变化，然后影响 Z，最后影响 X。

模型只看 X。

### 模型具体做什么？

第一步：根据历史 X 估计 Y 的概率分布。

\\[ P(Y_t\mid X\_{1:t}) \\]

第二步：根据 Y→Z 的关系预测 Z 的未来分布。

\\[ P(Z\_{t+h}\mid X\_{1:t}) \\]

第三步：根据 Z→X 的关系预测 X 的未来分布。

\\[ P(X\_{t+h}\mid X\_{1:t}) \\]

第四步：判断未来 X 是否可能进入预测失效区域。

例如：

\\[ P(E\_{t:t+h}=1\mid X\_{1:t})>0.9 \\]

其中 E 表示未来预测失效事件。

这里的 0.9 只是实验初始示例，正式阈值必须在独立正常校准集上确定。

### 设置五种对照

| 方法           | 研究目的        |
| ------------ | ----------- |
| 只看 X 的 CUSUM | 传统变化检测      |
| X 预测误差       | 常规失效检测      |
| 只估计 Y、Z      | 检验隐藏状态本身的作用 |
| 只估计因果连接      | 检验关系信息的作用   |
| 隐藏状态＋概率传播    | 检验你的完整思路    |

另外设置一个 Oracle：

直接提供真实 Y、Z 和真实参数。

它是理论参照，不是实际方法。

### 什么结果才算成功？

例如：

| 方法     | 平均预警时刻 | 误报率 |
| ------ | ------ | --- |
| CUSUM  | 305    | 5%  |
| 预测误差   | 310    | 5%  |
| 仅隐藏状态  | 302    | 5%  |
| 概率传播模型 | 295    | 5%  |

以上仅是理想结果的示意，不是已经取得的实验结果。

真正要验证的是：

在相同误报率下，概率传播模型能否比传统方法更早发现未来预测失效？

同时必须统计全部事件的提前覆盖率，不能只统计成功报警的轨迹。

## P3：研究因果连接变化，而不是只有 Y 变化

这是防止你的模型只会检测上游异常的重要实验。

设置：

\\[ Y、Z\text{ 保持正常} \\]

但是：

\\[ \beta\_{ZX}:0.8\rightarrow0.2 \\]

也就是 Z 本身正常，但它对 X 的作用明显减弱。

模型需要判断：

- Y 是否异常？
- Z 是否异常？
- Z→X 的连接是否发生变化？
- 未来 X 的预测风险是否升高？

这里最重要的是不能把隐藏状态异常和连接异常混为一谈。

建议再做两组：

| 场景   | 变化内容          |
| ---- | ------------- |
| P3-A | Y→Z 减弱，Z→X 不变 |
| P3-B | Z→X 减弱，Y→Z 不变 |

然后比较：

- 只监测隐藏状态。
- 只监测因果连接。
- 同时监测隐藏状态与因果连接。

如果只监测 Y、Z，会漏掉某些连接失效事件。

如果只监测连接，又可能漏掉上游状态异常。

因此两者需要联合考虑。

## P4：最终验证动态因果失效预警

前三步成功后，再做综合实验。

建议至少包含六种情况：

| 场景 | 系统变化       |
| -- | ---------- |
| A  | 上游 Y 突然变化  |
| B  | 上游 Y 渐进变化  |
| C  | Y→Z 传递关系减弱 |
| D  | Z→X 连接减弱   |
| E  | 多条因果连接同时变化 |
| F  | 正常波动，没有失效  |

最后比较：

1. 传统 CUSUM。
2. GLR。
3. 预测误差报警。
4. ACI。
5. ACI＋CIR。
6. 你的概率状态传播模型。

统一评价：

- 失效事件检出率。
- 误报率。
- 提前预警时间。
- 提前预警覆盖率。
- 隐藏状态恢复准确性。
- 因果连接估计误差。
- 概率预测校准程度。

这样才能证明你的方法究竟比现有方法多提供了什么。

# 三、这里有一个非常重要的实验原则

你之前的 L1～L3 已经告诉我们：单变量观测可能存在不可识别性。

所以，我建议每个阶段都保留三种数据设置：

设置 A：完全未知的 X-only

实际目标

训练和推断只允许使用 X，不提供隐藏变量和真实参数。

设置 B：已知结构，未知参数

只告诉模型可能存在 Y→Z→X，不告诉它真实参数。

用于研究在结构假设帮助下，参数和状态能否被恢复。

设置 C：已知真实方程的 Oracle

允许使用真实系统方程和参数，但仍然只观测 X。

用于估计当前观测条件下的理论恢复上限。

这三种设置不能混为一谈。

特别是 B 设置成功，不代表 A 设置也成功。

另外，你的模型还需要一个重要能力：当数据不足以判断时，能够输出“不可识别”或“证据不足”，而不是强行给出一条因果链。

# 四、我建议你下一步实际执行什么？

不要马上开展 P1～P4。

我建议下一轮先完成一个独立实验：

下一轮实验建议

P0-P1：可观测性与概率状态估计联合验证

研究问题：

在只观测 X、未知真实 Y、Z 和具体参数的情况下，模型能否恢复隐藏状态的概率分布？什么条件下可以，什么条件下不可以？

实验要求：

1. 沿用原来的三变量线性高斯系统。
2. 保留原 L1 数据和模型作为对照。
3. 新增不同噪声、传递强度和持续性条件。
4. 训练阶段只允许使用 X。
5. 测试阶段才使用真实 Y、Z。
6. 增加联合概率估计和概率校准评价。
7. 与卡尔曼滤波、平滑和 Oracle 比较。

本轮不进行因果预警，不修改因果连接。

预期交付：可观测性边界图、隐藏状态概率恢复结果、不同方法的性能比较，以及进入 P2 的条件。

# 五、关于创新性，我的最终判断

我不建议把创新点写成“首次利用单变量恢复隐藏变量”，因为单变量状态空间重构、非线性可观测性和单序列因果分析已经有不少研究。

更值得争取的创新是：

创新点一： 在部分观测条件下，研究隐藏状态的概率可恢复性及其可识别边界。

创新点二： 利用隐藏状态之间的动态概率传播，区分上游状态变化和下游因果连接失效。

创新点三： 将概率传播结果转化为预测失效风险，在相同误报率下验证是否能获得比传统方法更大的提前量。

这三个创新点有前后依赖关系，而且每一个都能设计独立实验。

我的建议是：先把 P0-P1 做扎实，再决定是否进入 P2。因为如果连隐藏状态概率分布都不可信，后面的因果传播预警就没有可靠基础。

你真正要证明的不是模型能够从 X 猜出 Y、Z，而是：在什么条件下，X 中的信息足以支持对隐藏状态和因果传播的概率判断，以及这种判断能否转化成真实有效的提前预警。

这才是这个课题最值得深入的科学问题。
